# Изолированное сравнение Whisper на Apple

Только исследовательский стенд. Он не меняет исходники, проекты, модели, настройки и историю Kat. У iPhone-стенда собственный bundle ID `app.kattranslator.whisper-research`; нельзя устанавливать его поверх Kat или направлять на контейнер Kat.

## Входы и измерения

Передайте частный JSON-массив с полями `id`, `language`, `path` для каждой записи. Пути разрешаются относительно манифеста. Аудио: моно, 16 кГц, little-endian Float32 PCM. Записи, эталоны, расшифровки, модели, журналы и подписанные сборки храните вне Git.

`Bench.mm` использует закреплённый whisper.cpp: Metal, Flash Attention, четыре потока, greedy, заданный язык, нулевая температура, без повторов с повышенной температурой и без предыдущего контекста. Загрузка модели измеряется отдельно. Проход 0 прогревает каждую запись; проходы 1–3 измеряются с чередованием порядка записей. JSON содержит текст, время, выборочные значения физической памяти и тепловое состояние. Измеряется только ASR: без записи микрофона, перевода, озвучки и предварительной обработки записи в Kat.

Варианты на каждом устройстве запускайте последовательно. Во втором блоке поменяйте порядок вариантов. Не запускайте параллельную GPU-нагрузку. Разные тепловые состояния учитывайте отдельными блоками. `phone_run.py --cool` ждёт номинального состояния до пяти минут; неудача записывается явно.

## Компоненты

- `CMakeLists.txt`: отдельная native-сборка; укажите `WHISPER_SOURCE`, каталог сборки храните в игнорируемой исследовательской области.
- `convert.py`: читает именно производственные F16 GGML-веса. Создаёт MLX F16 либо upstream Core ML-энкодер, ориентированный на ANE, с точностью FP16. Для Core ML нужны закреплённый whisper.cpp и его Python-зависимости. Пакет компилируется через `xcrun coremlc compile`.
- Q8: закреплённый квантователь whisper.cpp с `q8_0`; проверьте хэши входа и результата.
- `CoreMLBridge.mm`: экспериментальная замена upstream-моста. `BENCH_COREML_UNITS=off`, `all`, `cpu-ne` выбирает native fallback, автоматическое размещение Core ML либо только CPU/Neural Engine. `BENCH_COREML_ENCODER` позволяет указать общий каталог энкодера. Vendor-исходники не меняются. Запрошенный режим не доказывает размещение каждой операции на ANE.
- `mlx_bench.py`: Python MLX для macOS с тем же PCM, заданным языком и нулевой температурой. Токенизация, обработка временных отметок и вычислительные ядра зависят от реализации.
- `phone_project.py`: создаёт отдельный native/Swift iPhone-проект. Укажите свою команду подписи и изолированные пути native/MLX.
- `MLXRunner.swift`: базовый Swift MLX. Upstream-декодер подавляет временные отметки и не идентичен Python MLX.
- `prepare_swift_fp16.py`: опциональный патч изолированного mlx-audio-swift. При `BENCH_MLX_FP16=1` мел-признаки и вычисляемое позиционное кодирование сохраняют FP16, не повышая вычисления энкодера до Float32. Применяется один раз к закреплённой ревизии; неожиданный исходный текст вызывает явную ошибку.
- `phone_run.py`: запускает только исследовательский bundle, копирует только его отчёт и завершает его процесс. Поддерживает общий Core ML-энкодер, выбор вычислителей, охлаждение и Swift FP16.

## Качество и интерпретация

Кроме времени сравнивайте расшифровки: названия, числа, даты, пропуски и выдуманные слова. Совпадение с F16 означает согласие, а не правильность. WER вычисляйте только по независимо известным эталонам; отличие от baseline не называйте WER. Неудачные прогоны и разные тепловые состояния храните отдельно. Загрузка измеряется в новом процессе, но может использовать кеш ОС и ранее скомпилированную модель.

Версии и измеренные результаты записаны в [датированном отчёте](../../../docs/benchmarks/apple-whisper-acceleration-2026-10-20/README.md). Ни один эксперимент не включает backend в основном приложении.
