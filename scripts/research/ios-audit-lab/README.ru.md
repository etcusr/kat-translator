# Kat Audit Lab — проверки аудита 22.10 на iPhone

[English](README.md) | **Русский**

Отдельная копия Kat для проверок O14–O17, O19 из [плана аудита](../../../docs/maintenance/audit-fix-plan-2026-10-22.md). Своё имя **Kat Audit Lab**, bundle `app.kattranslator.voicelab` (существующий профиль разработки, действует до 20.10.2027; новый App ID не регистрируется), свой контейнер данных. Рабочая Kat (`app.kattranslator`) не переустанавливается, её контейнер не читается и не пишется. Расширение Live Activity в копию не входит: для его bundle профиля нет.

## Место

| | iPhone | Mac |
|---|---:|---:|
| Приложение | 0,21 ГБ | — |
| Index 9B + Index 2B + голоса Irina/Lessac (копируются с Mac) | 7,23 ГБ | 0 (копируются напрямую из `model-store`) |
| Whisper Q8, скачивается внутри копии (это и есть проверка O16) | 0,87 ГБ | — |
| Запас на время загрузки (проверка места приложения: ×2 + 256 МБ) | 2,0 ГБ | — |
| Сборка копии в `.build/audit-lab-2026-10-22` | — | 0,8 ГБ |
| **Итого свободного места до начала** | **≈ 10,5 ГБ, лучше 12 ГБ** | ≈ 1 ГБ |

После проверок копия удаляется целиком вместе с контейнером: `xcrun devicectl device uninstall app --device <id> app.kattranslator.voicelab`. Это освободит всё место выше.

## Подготовка (уже сделано)

`prepare.py --work .build/audit-lab-2026-10-22 --commit <коммит>` — снимок закоммиченного кода, без незакоммиченных правок. `build.sh <work>` — сборка Release и проверки: bundle ID, нет вложенного расширения, подпись, entitlement increased-memory-limit.

## Установка (только с согласия владельца)

`provision.py --device <UDID> --work .build/audit-lab-2026-10-22 --model-store model-store`:
- ставит только копию; отказывается, если копия уже стоит;
- копирует модели с квитанциями в её контейнер; при первом запуске приложение само проверяет SHA;
- сравнивает список приложений Kat до и после и проверяет, что рабочая Kat не изменилась.

Перед тяжёлыми шагами — термо nominal на Mac и спокойный iPhone (заряд ≥ 50 %, не в руках, рабочая Kat закрыта).

## Проверки

**O16 — загрузки** (Whisper Q8, 0,87 ГБ, по сети):
1. Начать загрузку → пауза на ~30 % → продолжить. Ожидается: продолжение с того же места, а не с нуля.
2. На ~50 % закрыть приложение смахиванием (или `devicectl device process terminate`), запустить снова. Ожидается: продолжение по resume data, а не «Начать заново».
3. Заблокировать iPhone и дождаться окончания в фоне, затем разблокировать. Ожидается: модель проверена и установлена, нет второй загрузки, в контейнере один `staging-*.bin` или ни одного.

Полная фоновая загрузка Index 9B (5,8 ГБ, нужно ещё ~12 ГБ свободного места) — только по отдельному решению.

**O14 — хвост записи** (после O16, нужен Whisper):
- Пять раз сказать фразу с отчётливым последним словом, например «…и купить хлеб», и нажать «Стоп» сразу после слова.
- Записать, сколько раз последнее слово пропало в распознанном тексте.
- Если пропало хотя бы раз — правка `AudioQueueStop(queue, false)` с приёмом буферов до остановки, потом повтор.

**O15 — восстановление камеры:**
1. Открыть камеру на тексте.
2. Настройки → Разработчик → «Сбросить медиасервисы», вернуться в Kat Audit Lab.
3. Ожидается: превью и распознавание восстанавливаются примерно за 5 с без закрытия камеры. Отметить, если превью осталось чёрным.

**O17 — камера (C1–C4, O18):**
- Живая камера на странице текста: оверлей обновляется. При переводе камеры на другой текст и повороте нет «призраков» прежнего оверлея.
- Снимок: оверлей появляется. «Сохранить» кладёт снимок в Фото. «Поделиться» даёт JPEG размером примерно 1–3 МБ.
- В истории появляется запись со снимком. Закрыть камеру сразу после снимка — запись в истории всё равно появляется.
- C4: при ошибке подготовки перевода кнопка «Запустить» доступна.
- Субъективно: нет подвисаний интерфейса при снимке.

**O19 — память при смене модели:**
- Запуск через `xcrun devicectl device process launch --device <id> --environment-variables '{"OT_MT_MEMORY_TRACE":"1"}' app.kattranslator.voicelab`.
- Голосовой перевод RU→EN на Index 9B, затем переключить модель на Index 2B и обратно при загруженном Whisper; три цикла.
- Снять `footprintBytes`, `processLifetimePeakBytes`, `availableBytes` из трассы и количество memory warning.
- Решение по M3 по данным: порог перед загрузкой Index и/или выгрузка Whisper до загрузки новой модели.

Все записи, тексты, логи и идентификаторы устройства остаются вне Git; публикуются только агрегаты. Копию не отправлять в Store/TestFlight.
