# Отдельная проверка потокового ASR

[English](README.md) | **Русский**

`probe.c` подаёт явно указанный приватный Float32 PCM 16 кГц mono в sherpa-onnx с сохранением состояния. Контейнеры приложений и микрофон не используются, перевод не выполняется, модели и настройки не меняются. JSONL содержит приватные расшифровки: не включать его в Git.

Модель `alphacep/vosk-model-streaming-ru`, revision `83bbf6f40059480e96251be8aed3d32bc7c80c33`: `am-onnx/{encoder,decoder,joiner}.int8.onnx` и `lang/tokens.txt`. Перед запуском сверить хэши весов с репозиторием модели. Лицензия модели Apache-2.0. Стенд использует имеющуюся в проекте sherpa-onnx; автоматически зависимости не скачивает.

Команды сборки и запуска с корня репозитория на Apple Silicon — в [английской инструкции](README.md). Аргументы: каталог модели, входной `.f32`, выходной `.jsonl`, режим подачи и декодирования. Режим подачи `0` — ускоренный файловый вход, `1` — ожидание каждых 160 мс; декодирование `1` — modified beam/10 paths, `0` — greedy.

Состояние одного потока сохраняется всю запись, произвольного сброса границ нет. Финальные 600 мс тишины выводят задержанный результат декодера, не выполняя повторное распознавание. Предварительный текст не является готовой фразой для перевода. Вычислительное время CPU исключает загрузку, ожидание подачи и сериализацию результата. Стенд проверен только на Mac; наличие C entry point не означает проверку на iPhone.
