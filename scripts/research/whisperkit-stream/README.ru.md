# Отдельный iPhone-тест потокового WhisperKit

Стенд использует отдельный контейнер `app.kattranslator.whisper-research`. Он не устанавливается поверх Kat, не читает её контейнер и не меняет настройки. Копии моделей и приватной записи хранятся только в игнорируемом `.build`. Нужны подпись разработчика и подключённый разблокированный iPhone.

## Методика

- Argmax `argmax-oss-swift` фиксируется на `9f99b5cb6a907730543823ad271b82532782a899` в отдельной временной копии.
- Модель Core ML `openai_whisper-large-v3-v20240930_626MB` и совместимый токенизатор Whisper large-v3-turbo заранее скачиваются локально. Перед копированием проверяются LFS-хеши весов.
- `prepare.py` создаёт отдельный Xcode-проект, копирует текущий Index backend Kat, подключает существующие iOS TranslationRuntime и OfflineCore. Во временный Argmax добавляются только доступ к состоянию, запуск файлового входа без разрешения микрофона и замер проходов. Алгоритмы сегментации, подтверждения и VAD не меняются.
- `ReplayAudio` подаёт тот же моно PCM Float32 16 кГц по 100 мс в реальном времени и использует расчёт относительной энергии Argmax. Микрофон, динамик и озвучка не используются.
- Стандартный `AudioStreamTranscriber` оставляет два последних сегмента предварительными. Законченные предложения подтверждённого префикса направляются в существующий Index 9B MTP2. Распознавание может продолжаться параллельно последовательной очереди перевода.
- После конца входа завершается текущий проход и распознаётся только неопубликованный интервал через `clipTimestamps`. Полной перепроверки, замены опубликованного текста и повторного перевода префикса нет.
- Подготовка/Core ML loading не входят во время записи. Старт разрешён после 30 секунд подряд в состоянии nominal, ожидание — до семи минут. При serious/critical запись прерывается. Сохраняются максимальное тепловое состояние, память, проходы ASR, подтверждения и моменты готовности переводов.
- Это сравнение полных потоковых конфигураций, **не только движков**: отличаются конверсия/квантизация, VAD, подтверждение и планирование относительно текущего Whisper.cpp Q8 + LocalAgreement. Черновик, подтверждённый ASR и готовый перевод измеряются отдельно.

## Запуск

Пути, подпись и устройство задаются явно и не коммитятся:

```
swift ExportPCM.swift <baseline-16k-mono-aiff> <private-16k-f32>
python3 prepare.py --work <ignored-work-dir> --argmax <disposable-pinned-checkout> --team <team>
xcodebuild build -project <work>/WhisperKitLab.xcodeproj -scheme WhisperKitLab -configuration Release -destination 'generic/platform=iOS' -derivedDataPath <work>/Derived -allowProvisioningUpdates
python3 provision.py --work <work> --device <device> --index <existing-Index-GGUF> --pcm <private-16k-f32>
```

Запускать только research bundle с `LAB_RUN=run-a`, `GGML_METAL_NO_RESIDENCY=1`. Обычный запуск ничего не тестирует. Забрать из этого контейнера `Documents/status.txt` и `Documents/run-a.json`. Повторять только после охлаждения и если первый результат требует проверки. Приватные материалы сохранять локально; публиковать агрегаты и качественные выводы без личных записей/текстов/ID устройства.

Базовые результаты явно датировать; хеш PCM должен совпадать. Файловую подачу нельзя называть проверкой живого микрофона или основного интерфейса. Сверка списков файлов и настроек до/после подтверждает сохранность основной аппки. После сохранения результатов можно удалить копии модели/аудио вместе с лабораторным контейнером; основную аппку не удалять.
