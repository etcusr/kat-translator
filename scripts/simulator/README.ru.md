# Проверки интерфейса Kat в iOS Simulator

[English](README.md) | **Русский**

Запуск настоящего iOS-приложения и повторяемых проверок навигации без подключения телефона. Скрипт создаёт или использует отдельный симулятор **Kat iPhone 17 Pro** с совместимым установленным runtime, собирает обычное приложение для ARM64 Simulator и устанавливает его туда. Он не стирает устройства и не устанавливает приложение на физический телефон. Установленные приложения Mac/iPhone и скачанные модели находятся вне этого процесса.

## Подготовка и первый запуск

Нужны используемый проектом Xcode и подготовленные нативные зависимости. Совместимый ARM64-образ iOS устанавливается один раз:

```sh
xcodebuild -downloadPlatform iOS -buildVersion 27.0 -architectureVariant arm64
```

Нужен именно профиль iPhone 17 Pro. Скрипт выбирает самый новый установленный runtime, заявляющий его поддержку (iOS 27.0 в текущем Xcode). Образ iOS 27.1 здесь поддерживает только iPhone Duo; существующие устройства и образ Duo сохраняются, автоматической подмены профиля нет.

Образ может занимать несколько гигабайт, плюс дополнительное место для установки. `run.py` не скачивает образ или модели незаметно. Нативные XCFramework должны содержать варианты iOS Simulator; успешная сборка для телефона сама по себе этого не доказывает.

Из корня репозитория:

```sh
python3 scripts/simulator/run.py
```

Команда выбирает самый новый установленный iOS runtime с поддержкой iPhone 17 Pro, запускает отдельный виртуальный iPhone, открывает Simulator или Device Hub (в зависимости от Xcode) и выполняет два XCTest-сценария:

1. Категории настроек, открытие/закрытие быстрой настройки, страницы моделей/распознавания/OCR/загрузок, поиск языка голосов и страница голосов. Нажатия по строкам разделов выполняются справа, вне названия.
2. Переходы Голос/Текст/Камера, поиск в меню языков, сохранение текста при смене режима и виртуальном Home/возврате, открытие/закрытие истории.

Используется синтетический английский текст. Аргументы запуска выбирают английский интерфейс и отключают автоматическую загрузку модели в память и мастер первого запуска **для процесса в симуляторе**. Быстрая настройка всё равно открывается из меню. Веса не скачиваются, запись и перевод не запускаются. Это проверка интерфейса, а не инференса или первого запуска после установки.

## Повторные проверки и результаты

```sh
# Использовать ранее собранное приложение; свежие изменения исходников могут отсутствовать.
python3 scripts/simulator/run.py --skip-build

# Не открывать окно Simulator.
python3 scripts/simulator/run.py --headless
```

Сборка приложения находится в `.build/SimulatorDerivedData`. Генерируемый проект тестов только для симулятора — в `.build/KatSimulatorUITests`; каждому прогону соответствует датированная папка `runs/` с журналами, `Navigation.xcresult`, машиночитаемым итогом и экспортированными снимками. Успех сообщается только при прохождении обоих тестов без пропусков. Проверки и результаты не меняют отслеживаемые Xcode-проекты или версию выпускаемого приложения.

Для ручной работы выберите **Kat iPhone 17 Pro** в Simulator/Device Hub. При работе на Mac владельца размещайте Simulator на встроенном экране MacBook; определяйте его по текущей конфигурации, не по запомненному номеру. Не переписывайте системные разрешения Accessibility ради обхода сбоя автоматизации.

## Локальные модели без полной второй копии

Проверка целостности намеренно не принимает симлинки на веса. На APFS используйте независимые клоны с копированием при записи:

```sh
python3 scripts/simulator/seed-models.py --whisper /absolute/path/to/turbo-q8_0.bin
python3 scripts/simulator/run.py --skip-build --model-check
```

Скрипт сверяет SHA существующего Whisper Q8 и клонирует Index 9B/2B, Denis и LJSpeech из хранилища установленного Mac-приложения. Ничего не скачивает, не заменяет существующие файлы и завершается ошибкой, если APFS-клонирование недоступно. Разрешён только выделенный запущенный симулятор iPhone 17 Pro. Квитанции независимы; кэши проверки Kat создаёт заново. Изменение или удаление клона не меняет исходник. Логический объём около 8,36 ГБ; неизменённые блоки разделяются с исходниками, фактическое новое место отдельно не измерялось.

Whisper и Index в симуляторе используют CPU: текущий путь mapped-buffer в MTLSimDevice аварийно завершается. При подготовке зависимостей пересоберите только симуляторный TranslationRuntime: `bash scripts/build-translation.sh iphonesimulator`. GPU-пути настоящего iPhone и Mac сохраняются. Отдельная проверка готовит распознавание/перевод и переводит короткий текст; она не проверяет качество микрофона/озвучки и не измеряет скорость телефона.

## Ограничения

Симулятор использует процессор, память и графическую среду Mac. Его время работы, нехватку памяти и нагрев нельзя выдавать за замеры iPhone. Аппаратной камеры нет; вход/выход с её экрана не доказывает качество захвата или OCR. Маршруты микрофона, прерывания, приостановка приложения телефоном, Live Activities и фоновые загрузки требуют проверки на физическом устройстве. iPad, увеличенный текст и все локализации требуют отдельных сценариев.

Команда не загружает приложение в App Store, не устанавливает его на телефон, не копирует модели и не выполняет очистку.
