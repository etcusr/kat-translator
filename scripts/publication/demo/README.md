# Website demonstration montage

**English** | [Русский](README.ru.md)

`build.py` composes real iPhone Simulator footage into a 1280 × 720 H.264 MP4 with a short animated Kat intro/outro and scene transitions. It requires Python with Pillow, FFmpeg and the macOS Arial fonts. The app view is scaled into a frame without replacing its contents; no translation result is generated by this script. Use neutral examples only.

Pass `--recording`, `--edit`, `--work` and `--output`. The edit JSON contains a `scenes` array; every entry has source `start`/`end` seconds, a short `label`, multiline `title`/`body`, and an optional `note`. Inspect the source at each cut before rendering. The script keeps scene playback at 1×; cuts and transitions shorten the overall sequence. Keep source recordings and intermediate files under ignored `.build/`; only a reviewed compact final MP4, poster belong in the site assets.

Record the ordinary app with actual inference in the dedicated simulator. Close native Kat first, use the shared heavy-job lock, and shut down the simulator afterwards. Never use the separate prepared-state screenshot app for a demonstration of translation. A simulator video is not a physical-iPhone performance or microphone test; label it accordingly. Record the source build, capture/test results, edit decisions and final hash in a dated publication report. Publishing is a separate authorized step.

## Tempo and music

The website export uses `finish.py` after `build.py`: pass the original silent `--master`, `--work`, `--output` and optional `--speed` (default 1.15). This needs NumPy. It synthesizes an original soft keys/plucked-note instrumental with an opening, theme, contrasting arpeggios, varied return and cadence without external samples, adds AAC stereo with fade-in/out, encodes a 30 fps video. Preserve the master in ignored storage; never process an already accelerated export again. Label the speed on the page. The music composition and synthesis source are part of this repository under its license.

The website has no subtitle tracks. Embedded English titles remain part of the picture.
