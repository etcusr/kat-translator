# Монтаж демонстрации для сайта

[English](README.md) | **Русский**

`build.py` собирает настоящую запись симулятора iPhone в H.264 MP4 1280 × 720: анимированные вступление/финал с котом и переходы между сценами. Нужны Python с Pillow, FFmpeg и шрифты Arial из macOS. Интерфейс масштабируется в рамку без подмены содержимого; скрипт не генерирует результат перевода. Использовать только нейтральные примеры.

Параметры: `--recording`, `--edit`, `--work`, `--output`. JSON монтажа содержит массив `scenes`; каждая запись — исходные секунды `start`/`end`, короткий `label`, многострочные `title`/`body`, необязательный `note`. Проверить исходник на каждой склейке. Внутри сцен скорость 1×; длительность сокращают склейки и переходы. Исходники и промежуточные файлы хранить в игнорируемой `.build/`; на сайт добавлять только проверенные компактный MP4, постер и субтитры.

Снимать обычное приложение с настоящим переводом в выделенном симуляторе. Сначала закрыть Kat на Mac, использовать общий замок тяжёлых задач, после записи выключить симулятор. Отдельную постановочную сборку для скриншотов не использовать для демонстрации перевода. Ролик симулятора не является проверкой скорости настоящего iPhone или микрофона; явно подписывать происхождение. Сборку, результаты съёмки/теста, монтажные решения и итоговый хэш записать в датированном отчёте. Публикация требует отдельного разрешения.
