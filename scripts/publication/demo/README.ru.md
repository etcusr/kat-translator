# Монтаж демонстрации для сайта

[English](README.md) | **Русский**

`build.py` собирает настоящую запись симулятора iPhone в H.264 MP4 1280 × 720: анимированные вступление/финал с котом и переходы между сценами. Нужны Python с Pillow, FFmpeg и шрифты Arial из macOS. Интерфейс масштабируется в рамку без подмены содержимого; скрипт не генерирует результат перевода. Использовать только нейтральные примеры.

Параметры: `--recording`, `--edit`, `--work`, `--output`. JSON монтажа содержит массив `scenes`; каждая запись — исходные секунды `start`/`end`, короткий `label`, многострочные `title`/`body`, необязательный `note`. Проверить исходник на каждой склейке. Внутри сцен скорость 1×; длительность сокращают склейки и переходы. Исходники и промежуточные файлы хранить в игнорируемой `.build/`; на сайт добавлять только проверенные компактный MP4, постер.

Снимать обычное приложение с настоящим переводом в выделенном симуляторе. Сначала закрыть Kat на Mac, использовать общий замок тяжёлых задач, после записи выключить симулятор. Отдельную постановочную сборку для скриншотов не использовать для демонстрации перевода. Ролик симулятора не является проверкой скорости настоящего iPhone или микрофона; явно подписывать происхождение. Сборку, результаты съёмки/теста, монтажные решения и итоговый хэш записать в датированном отчёте. Публикация требует отдельного разрешения.

## Темп и музыка

После `build.py` сайт использует `finish.py`: передайте исходный немой `--master`, `--work`, `--output` и необязательный `--speed` (по умолчанию 1.15). Нужен NumPy. Скрипт синтезирует оригинальную мелодию с мягкими клавишами и щипковыми нотами: вступление, тема, контрастные арпеджио, вариация и завершение без внешних сэмплов, добавляет стерео AAC с плавным началом/окончанием, кодирует видео 30 fps. Мастер хранить в игнорируемой папке; повторно ускоренный файл не обрабатывать. Скорость указывать на странице. Композиция и исходник синтеза входят в репозиторий под его лицензией.

На сайте нет дорожек субтитров. Английские титры внутри кадра сохранены.

## Варианты музыки

`music_options.py --video <выбранный-mp4> --work <игнорируемая-папка> --output <папка-превью>` создаёт варианты `playful` и `airy` в MP3/MP4. Использует NumPy/FFmpeg, синтезирует оригинальные аранжировки и копирует видеопоток без изменений. Выбранный ролик главной страницы не заменяет.
