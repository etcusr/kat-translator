# Постановочные экраны iPhone

[English](README.md) | **Русский**

Подготовленные оригинал/перевод для «Голоса» и пример таблички для «Изображения» отрисовываются настоящими SwiftUI-экранами. Это **презентационные состояния**, а не проверка распознавания, перевода, воспроизведения или камеры. Модели не запускаются. Кнопки результата включены для съёмки состояния; это не рабочее приложение.

`prepare.py --output .build/<новая-директория>` копирует закоммиченные Apple-исходники в новую игнорируемую папку и меняет только копию. Зависимости читаются через симлинк; веса и данные установленных приложений не копируются и не меняются. Компиляция для физического устройства запрещена. Рабочие исходники и готовые Store-пакеты не затрагиваются.

Собрать скопированный `source/apps/ios/OfflineTranslator.xcodeproj` с `-sdk iphonesimulator`, Debug и `CODE_SIGNING_ALLOWED=NO` в отдельную DerivedData. Использовать только выделенный симулятор Kat iPhone 17 Pro, не телефон. Сначала закрыть Kat на Mac и занять общий lock тяжёлых задач. Создать независимый тестовый проект командой `scripts/simulator/run.py --screenshots --prepare-only`, заменив в нём ссылку на `PublicationScreenshots.swift` файлом `Screenshots.swift` из этой папки.

Установить постановочную сборку только в симулятор, запустить четыре теста `PublicationScreenshots`, экспортировать вложения XCTest. Требуются четыре успешных теста без ошибок/пропусков и восемь именованных PNG. Проверить изображения глазами. Передать папку вложений через `--ios-presentation` в `collect-interface-captures.py`; манифест и галерея отличают подготовленные состояния от снимков настоящего выполнения моделей. Время и кнопки постановочного состояния не доказывают скорость или работоспособность.

После съёмки установить обычное приложение из `.build/SimulatorDerivedData/Build/Products/Debug-iphonesimulator/OfflineTranslator.app` поверх постановочного (без удаления приложения/данных), восстановить обычный тестовый проект и выключить симулятор. Сохранить JSON происхождения и локальный результат тестов. Постановочную сборку не распространять и не загружать в магазин.

В текущий набор сборщик включает только кадры Голос; скриншоты камеры исключены владельцем 23 октября.
