# Общее локальное хранилище

[English](README.md) | **Русский**

`downloads/` — единственное дерево загруженных моделей и голосов для всех платформ.
Существующее содержимое перемещено без копирования. `Dependencies/downloads` —
временная символическая ссылка сюда для старых vendor-скриптов.

Модели не размещаются в `apps/ios`, `apps/macos` или `apps/android` и не входят
в APK. На отдельном устройстве приложение хранит свою проверенную локальную
копию: песочницы iOS/Android не могут напрямую использовать хранилище компьютера.

Общие описания пакетов и SHA-256 находятся в `assets/catalogs/` и
`docs/android/portability-contract.json`. Формат определяет совместимость:
GGUF/ONNX универсальны при поддержке архитектуры runtime; Core ML предназначен
для Apple, исполняемые библиотеки собираются отдельно для каждой ОС/ABI.
