# Android app

[English](README.md) | **Русский**

Piper начинает воспроизведение по готовым фрагментам; одна модель Whisper и один голос Piper остаются в кэше на устройствах с достаточным запасом памяти. Загрузка голоса может идти параллельно переводу. Остановка отбрасывает ожидающие фрагменты, а завершённый звук остаётся доступен для повтора и экспорта. Озвучка частичного перевода пока остаётся отдельным следующим этапом. [Реализация, времена и ограничения](../../docs/android/benchmarks/2026-10-17-streaming-cache/README.md). На записи 28,86 с на Pixel первый звук: 25,61/25,28 → 20,34/17,95 с (первый/повторный запуск); тексты распознавания и перевода совпали точно. Это результаты конкретного замера, а не гарантия времени для любых записей.

Озвучка VITS/Piper использует до четырёх потоков CPU с прежними настройками модели/голоса. На Pixel измеренный синтез текста из 257 символов сократился с 17,38 до 10,42 секунды. Для других устройств нужны отдельные замеры. [Разбивка времени и проверки](../../docs/android/benchmarks/2026-10-17-tts-latency/README.md).

В голосовом режиме сразу показаны карточки оригинала и перевода; оригинал остаётся раскрытым. При воспроизведении, включая автоматическую озвучку, активный динамик заменяется крестиком остановки и возвращается после остановки или окончания. Проверено на Pixel: 4 теста устройства. [Проверка](../../docs/android/benchmarks/2026-10-17-voice-results/README.md).

Текущая сборка: **0.4.6 / versionCode21**, Debug, ARM64/API31+. Проверенная платформа — Pixel9Pro/Mali-G715. [Общий текущий статус](../../docs/CURRENT_STATE.ru.md).

Kotlin/Compose: Voice/Text/Camera, языки, история, настройки, модели, загрузки, аудио и общие анимации. Начальный выбор — «Авто»: установленный Index 9B → 2B на мощном устройстве, поддержанный OPUS → 2B → 9B на остальных. Доступны OPUS Big CTranslate2 CPU INT8 (EN-пакет и отдельные направления), Index 2B Q4_K_M Vulkan без MTP и Index 9B Q4_K_M Vulkan/MTP. Сохранённый выбор не сбрасывается.

ASR Auto: RU → GigaAMv3, остальные поддержанные Parakeet языки → ParakeetTDTv3; обязательный пакет предлагается скачать. Ручной выбор имеет приоритет. Голос/камера требуют явного исходного языка, текстовое Auto сохраняется. OCR: bundled ML Kit для поддержанных письменностей, русский PP-OCR.

Каталоги: `../../assets/catalogs`; модели/голоса: `../../model-store`. Веса не входят в APK. Native C ABI: `../../shared/native`. Mali Q6 и другие Android-only patches применяются к build-копии, без изменения общего vendor/Apple Metal.
