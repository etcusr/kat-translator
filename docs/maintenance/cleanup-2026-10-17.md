# Completed-test and build cleanup — 17 October 2026

## Verification

Before deletion, the exact allowlist and 210,912 candidate entries were recorded. No tracked Git files, retained symlink targets or open file handles overlapped the candidates. Six package copies matched retained releases by SHA-256. Both IPA extractions matched all 3,456 entries each; the Mac ZIP staging app and installed-app copy each matched 25,199 file/link entries, ignoring Finder metadata.

After deletion:

- All 173 selected paths were absent.
- All 417,238 protected file/link entries remained. Metadata was unchanged for 417,237; one retained Gradle daemon log appended background health-check, lock and local Java RMI debug messages, with the same inode and permissions.
- All 2,684 nonvolatile SHA-256 checks matched, covering tracked source and retained distribution/current Android APK files. One additional hash check for Finder `.DS_Store` changed and is excluded from the content-integrity claim.
- Git's working tree remained clean until this documentation update.

Finder recreated `.DS_Store` during deletion. The operation stopped, verified the remaining contents against the original inventory, and resumed only after confirming the extra file was valid Finder metadata. No arbitrary new files were accepted.

This was filesystem preservation validation, not a fresh compilation or device test. Subsequent builds may take longer while regenerating caches. Detailed manifests, comparison scripts and raw checks remain locally under ignored `.build/cleanup-2026-10-17/`; private file inventories and journal contents are not published.
