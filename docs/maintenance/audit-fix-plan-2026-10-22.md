# План проверки и исправлений по аудиту — 22 октября 2026

Источник: [аудит iOS](ios-code-audit-2026-10-22.md), [аудит macOS](macos-code-audit-2026-10-22.md). Порядок по решению владельца: **сначала macOS** (включая общий код, который на неё влияет), затем iOS.

Правила:

- Перед исправлением подтвердить, что проблема есть: тест, который падает до правки (red → green), либо иное воспроизведение. Не подтвердилось — статус «не подтвердилось», без правки (пример: хоткеи ⌥1/⌥2/⌥3 работают на macOS 27.0.1).
- На каждое исправление — автоматический тест, где возможно. Одно исправление — один небольшой коммит; запись для двойной проверки GPT/Codex в `GPT_HANDOFF.md`.
- Без установки поверх установленного приложения, без удаления моделей/истории/настроек, без Store и push.
- Всё, что требует участия владельца (ручная проверка, решение о поведении, сертификаты, устройство), — в разделе «Нужен владелец».

Статусы: ⏳ ждёт · 🔍 проверяется · ✅ исправлено (коммит, тест) · ❌ не подтвердилось · 👤 нужен владелец · ⏸ отложено.
