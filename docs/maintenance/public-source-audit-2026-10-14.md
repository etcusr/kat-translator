# Проверка истории перед открытием исходников

Дата: 14 октября 2026. Код под GPL-3.0-or-later; GitHub пока приватный. Выполнена проверка истории на личные данные и секреты. Это проверка публикации исходников, не допуск бинарных выпусков в магазины.

## Первоначальная проверка

Базовый проверенный HEAD — `47bc1b877f5ee7df4b1bb2764f40371c30014a1e`: 63 коммита main, 37 ещё не были на origin/main. После fetch проверены все объекты, достижимые из main и origin/main: **1 948 уникальных blobs, 50 066 632 байта**, максимальный объект 8 532 392 байта. На сервере обнаружена только ветка main; других веток, тегов, releases, issues, Actions runs/artifacts не было. Wiki, Pages и Discussions были выключены.

Известных пользовательских ключей, паролей, device IDs и локального signing team ID в публикуемых объектах не найдено. Публикуется только main: внутренние refs/checkpoints инструментов разработки и ignored-архив прежней истории не входят в область публикации. `--all`/`--mirror` не использовать. На этом этапе дополнительная очистка ещё не выполнялась; последующие результаты приведены ниже.

## Проверки

- Gitleaks **8.30.1**, официальный архив с проверенной SHA-256: просмотрел 61 непустой diff. Найдены **два ложных срабатывания** на 64-символьные SHA-256 полей `cApiHeaderSHA256` и `arm64CAPI_SHA256` в историческом `Dependencies/android-media.lock.json`, коммит `0509e1c`. Это контрольные суммы артефактов, не credentials. Нельзя описывать этот результат как «сканер выдал ноль».
- Все достижимые текстовые и бинарные blobs проверены на локальные пути, известные идентификаторы устройств, заголовки private keys и характерные секреты. Шаблон `/Users/USER` и тестовый URL `https://user:password@example.org/a` — намеренные фикстуры, не личные данные.
- Метаданные авторов/коммиттеров используют только псевдоним проекта и GitHub noreply. Email авторов upstream в обязательных notices сохранены; они не являются приватной перепиской пользователя.
- Метаданные 167 исторических медиаобъектов проверены через ffprobe: не обнаружены поля автора, комментариев, названий или GPS. Две Android audio fixtures дополнительно распознаны локальным Whisper: синтетические фразы о голосе/поезде/заказе, без личного содержания. Полная ручная прослушка всех голосовых превью не выполнялась.
- В истории нет пакетов подписи, контейнеров телефонов, баз пользовательской истории и установщиков. Встроенный fastText `.ftz`, ресурсы eSpeak и синтетические превью являются ресурсами приложения; утверждать, что в Git нет вообще никаких моделей/медиа, неверно.
- `.build`, `.github-publish` и локальный signing config исключены Git. Raw-отчёты и сканер находятся в ignored `.build/public-source-audit-2026-10-14/`; их не публиковать.

Новые коммиты лицензии, исследования голосов и страницы privacy также должны пройти проверку staged-состава и повторный scan перед разрешённым push. Публичный контакт, предоставленный пользователем для страницы privacy, допустим к публикации и не является найденным секретом.

## Ограничения

Pattern scanning и проверка метаданных не являются математической гарантией отсутствия любой личной информации. Проверка не распространяется на ignored-архивы/контейнеры, которые остаются локально. Она не подтверждает лицензии всех голосов, соответствующий исходный код каждого готового бинарника, требования App Store или сетевое поведение SDK. Эти вопросы отдельно ведутся в [очереди публикации](../publication/OPEN_QUESTIONS.md).

Локальные незавершённые изменения iOS46/миграции, privacy manifest и тестовой оболочки сохранены отдельно и не включаются в публикацию исходников этой задачи.

## Дополнительная очистка публикационных текстов

Из двух последних коммитов удалён не относящийся к проекту контекст. История main заменена с force-with-lease; локальная резервная копия осталась в ignored-каталоге. Повторная проверка 2 038 объектов main не нашла целевых персональных упоминаний. Gitleaks: те же два ложных срабатывания на SHA-256, новых нет.

GitHub временно переведён в private. Старый commit-объект по прежнему SHA пока доступен через авторизованный API после замены ветки; удаление недостижимых объектов/кэша на стороне GitHub не подтверждено. Не объявлять полное удаление серверных копий или восстанавливать публичность без решения этого вопроса.
