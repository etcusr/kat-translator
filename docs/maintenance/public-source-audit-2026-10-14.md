# Проверка публичного снимка исходников

Дата: 14 октября 2026. Код Kat опубликован под GPL-3.0-or-later в новом [репозитории](https://github.com/etcusr/kat-translator). Публичная история начинается с `cba4b15260bd8de758577adaef89f2f49e66ca9a` (`Initial source import`); старые коммиты не переносились. Это публикация исходников, не допуск бинарных выпусков в магазины.

## Состав и проверки

- Начальный снимок содержит **1 506 отслеживаемых файлов**. Его Git tree совпадает с проверенным состоянием проекта до создания новой истории. Незавершённые рабочие изменения не включены.
- Служебные журналы, локальные инструкции, архивы обсуждений, контейнеры устройств, сборки и скачанные веса исключены. Ресурсы приложения, синтетические превью, лицензии и notices сохранены.
- Сканер Gitleaks 8.30.1 обнаружил два ложных срабатывания в `Dependencies/android-media.lock.json`: значения `cApiHeaderSHA256` и `arm64CAPI_SHA256` являются контрольными суммами файлов. Новых находок нет. Дополнительно проверены исключённые пути, заголовки private keys и известный локальный пользовательский путь.
- Автор начального коммита — псевдоним проекта и GitHub noreply; сообщение краткое, без служебных подписей.
- До открытия нового репозитория GraphQL-проверка подтвердила отсутствие **139 старых коммитов и 4 объектов удалённых служебных файлов**. Новый начальный коммит доступен в том же запросе, поэтому отсутствие старых объектов не объясняется отсутствием доступа к репозиторию.
- После открытия без авторизации проверены три старых SHA: их веб-страницы возвращают HTTP 404, API сообщает `No commit found for SHA` (HTTP 422). Новый коммит доступен (HTTP 200).

## Публикация сайта

[Deployment](https://github.com/etcusr/kat-translator/actions/runs/38491945765) завершён успешно. Главная страница https://etcusr.github.io/kat-translator/ и политика https://etcusr.github.io/kat-translator/privacy/ доступны без авторизации (HTTP 200); HTML побайтово совпадает с исходниками. Публикуется только каталог `site/`.

## Границы результата

Проверка подтверждает опубликованный состав и недоступность проверенных старых объектов в новом репозитории. Она не подтверждает физическое уничтожение внутренних резервных копий GitHub или копий, ранее полученных третьими лицами. Прежняя история сохранена только в локальном ignored-архиве и не отправляется.

Pattern scanning не является гарантией отсутствия любой возможной конфиденциальной информации. Лицензии моделей, инвентаризация конечных артефактов и магазинные декларации проверяются отдельно по [очереди публикации](../publication/OPEN_QUESTIONS.md).
