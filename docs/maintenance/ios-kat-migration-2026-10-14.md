# iOS 0.5.16 / build46: новый идентификатор и перенос данных

Переход: `org.openoffline.translator.prototype` → `app.kattranslator`; расширение — `app.kattranslator.downloads`. Новый URL загрузок — `kattranslator://downloads`, чтобы Live Activity открывала новое приложение при сохранённой старой установке.

## Проверено

- Свежая полная резервная копия старого контейнера: 9 223 файла, 34 955 394 713 байт. Список файлов и размеры сверены с остановленным приложением: несовпадений нет.
- Для 8 187 файлов моделей и пользовательских данных, 29 093 620 971 байт, рассчитаны SHA-256. Из хэш-манифеста исключены восстанавливаемые кэши проверки пакетов и состояние загрузок.
- Собрана Release-версия с RU/EN/ES/TR и тестовым модулем миграции; строгая проверка подписи прошла.
- Новое приложение установлено отдельно. Старое приложение и обе локальные резервные копии сохранены.

## Проверка на iPhone

Перенос Documents, данных приложения и настроек завершён. Наличие и размеры перенесённых файлов сверены; значения настроек совпали при обратном чтении из нового контейнера.

Первый SHA-тест остановился на `History/history.json`: приложение пересохраняет индекс через JSONEncoder при применении политики истории, меняя порядок ключей. Полное сравнение разобранного JSON подтвердило равенство всех 68 записей. Это различие представления, не потеря записей; побайтовый хэш индекса после запуска неприменим. Индекс проверен отдельно по содержимому.

Повторный тест на устройстве проверил SHA-256 **8 186 файлов, 29 093 584 099 байт** — PASS (14 с). Два голосовых теста новой сборки также прошли:

- `testAfterStopDetectsLanguageAndSwitchesAutoModels`: RU → DE → RU, реальный ASR → Auto MT → TTS, переключения OPUS → Index 9B → OPUS — PASS (74,9 с).
- `testPreviewResolvesActualLanguageBeforeTranslation`: preview распознавания русского языка с переходом Index 9B → OPUS — PASS (4,3 с).

Это тесты синтетических аудиофайлов внутри устройства, не новый прогон физических микрофонов и не субъективная оценка произношения. Визуальная приёмка всех экранов ES/TR не выполнялась.

Чистая обычная Release-сборка без тестового модуля установлена поверх нового ID и успешно запущена. После запуска все исходные значения настроек и содержимое 68 записей истории повторно совпали с резервной копией. Строгая проверка подписи и отсутствие `.xctest` в итоговом bundle подтверждены. Артефакт сохранён в `dist/ios/Kat-translator-0.5.16-build46.app`. Старое приложение сохранено.

После hosted-тестов требуется `clean build`: обычная инкрементальная сборка сохранила прежний `ArticleRuntimeTests.xctest` в папке результатов. Проверка состава остановила установку этого промежуточного артефакта; чистая сборка устранила остаток. Проверки документации и состава ресурсов: 10 тестов — PASS.

Архив и App Store IPA, экспортированные ранее в этот день, предшествуют изменениям локализации и текста конфиденциальности. Они не представляют текущий код и не загружались в TestFlight/App Review.
