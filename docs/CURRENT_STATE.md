## Что внедрено сейчас

### Перевод и первоначальная настройка

- **«Авто» — начальный выбор перевода на всех трёх платформах.** Сохранённый ручной выбор не сбрасывается. Тест устройства перед выбором языков занимает примерно 3–5 с, измеряет CPU/Metal или Vulkan GPU без скачивания моделей; результат — оценка скорости 9B, не замер перевода. Запас на нагрев: 0,7 на телефонах, 1,0 на Mac. Порог мощного устройства: RAM ≥11,5 ГБ и оценка ≥6 ток/с на iPhone, ≥8 на Mac/Android.
- Во время перевода «Авто» выбирает из установленных моделей: мощное устройство → Index 9B, затем 2B; остальные → OPUS для поддержанной пары, затем 2B и 9B. Apple сначала проверяет старый EN-пакет, затем отдельные направления. Модель разрешается после фактического определения языка текста/речи (включая preview); список языков Auto не ограничен текущим движком. При ручном выборе автоматической подмены модели нет. Источники: `TranslatorState.resolveModel`, `AutoTranslation.resolve`, `PackageDownloadCoordinator`.
- «Ваши языки» собирает план MT/ASR/TTS и общий объём. Для мощного устройства планируется 9B; для остальных — доступный OPUS для выбранных пар, иначе 2B. Android поддерживает несколько своих языков; Apple — один свой язык и языки перевода. Подробности: [Android Auto](android/benchmarks/2026-10-13-auto-translation/README.md), [Apple](benchmarks/apple-device-check-2026-10-13/README.md).
- **Index 2B внедрён на iPhone, Mac и Android.** Официальный Q4_K_M, 1 312 164 352 байта: Metal на Apple, Vulkan на Android. На Mac это отдельный llama.cpp backend, а не MLX 9B. На Android MTP включается только для 9B. 2B быстрее в проверенных примерах, но уступает 9B по качеству; полноценная языковая приёмка не завершена.
- **OPUS-MT Big — 54 направления** в каталоге `opus-direction-packages.json` (35 языков). Это пакеты моделей: один групповой пакет может обслуживать несколько пар. 54 OPUS-направления работают через CTranslate2 CPU INT8 на всех платформах. Старый EN↔RU/UK/BE пакет на современном Mac использует отдельный PyTorch Metal FP16 worker; на телефонах — CT2 CPU.
- Краткая подпись охвата EN ↔ ~30 языков означает объединение партнёров EN в обоих направлениях, а не обещание обеих сторон для каждого языка. Точные маршруты заданы каталогом; PT→EN отсутствует, EN↔KO и RU→сербский латиницей исключены. Из сети скачиваются 10 направлений, остальные 44 — ручная установка до появления хостинга. При нескольких маршрутах выбирается первый установленный, поэтому отсутствующий bg-en не блокирует установленный zls-en. Прямые пары без EN уже внедрены; скрытого pivot нет. [Направления](android/benchmarks/2026-10-13-opus-directions/README.md).
- Меню «Направления OPUS» на всех платформах: поиск, выбор направлений, статус/размер, общий объём, одна кнопка скачивания. Apple-кнопка использует общее сетевое подтверждение с объёмом, включая повторно разрешённые сотовые загрузки. Android setup учитывает уже установленные ручные направления; Auto-переход OPUS/Index освобождает прежний контекст и lease. Совпавшие исходный/целевой языки обходят MT. Пакеты пар из Android 0.3.9 заменены пакетами направлений; старый отчёт описывает только тот этап.

### Android

- Compose: текст, голос, камера, история, загрузки, воспроизведение и отправка оригинала/TTS. Index 9B — GGUF Vulkan/MTP, Index 2B — GGUF Vulkan без MTP, OPUS — CT2 CPU INT8. `PackageCatalog.DEFAULT_TRANSLATION_BACKEND="opus"` — legacy-константа; текущую начальную настройку `auto` задаёт `TranslatorState`.
- CPU-часть ggml собирается под ARMv8.2 dotprod/FP16; `index_jni` проверяет HWCAP до запуска. i8mm не включён. Это не ускорение Vulkan-пути. Mali-G715 Q6 оптимизации сохранены; конкретные измерения относятся к [выпуску 0.3.7](android/benchmarks/2026-10-12-mali-q6-kernels/README.md).
- ASR Auto по явно выбранному языку: русский → GigaAM v3; остальные 24 языка из 25-язычного каталога Parakeet → Parakeet TDT v3. Недостающий обязательный пакет предлагается скачать; ручной выбор имеет приоритет. Прежняя ASR-проверка охватывает RU/EN; в свежем голосовом прогоне также проверен DE/Parakeet, включая микрофон. Это не приёмка всех 25 языков. Для прочих языков остаются отдельные on-device/Whisper/Meta пути; облачного fallback нет. Импорт PCM в системную службу требует Android13+.
- Голос и камера используют явный язык; «Авто» настроек ASR выбирает движок, а не определяет неизвестный язык речи. После ASR режим Auto MT получает язык результата и выбирает установленную модель. Текстовое автоопределение остаётся.
- OCR: bundled ML Kit для поддерживаемых письменностей, русский PP-OCR с mobile detector. Нет подстановки Latin OCR для неизвестной письменности.
- Записанный звук для воспроизведения/экспорта нормализуется с усилением до32×; raw PCM для ASR не меняется. Сохранены тайминги этапов, подготовка/выгрузка модели, история и анимации.

## Исследования и границы внедрения

- **Index 2B против 9B (12–13.10)**: исследование предшествовало интеграции 2B на всех платформах. На выбранных статьях 2B быстрее в 3,5–4,7 раза, но уступает по качеству; были также небольшие многоязычные пробы. Это не полная приёмка всех языков и не универсальный коэффициент ускорения. [Сравнение устройств и качества](benchmarks/index2b-cross-device-2026-10-13/README.md), [первоначальное исследование](android/benchmarks/2026-10-12-index-alternatives/README.md).
- **Компактные пары (13.10)**: Tower+, Hy-MT2, EuroLLM и NLLB не внедрены. Прямые OPUS-пары, рассмотренные в исследовании, впоследствии внедрены через каталог направлений. [Историческое сравнение](benchmarks/compact-pair-models-2026-10-13/README.md).
- **Скорость Pixel (12.10)**: 9B ограничен полосой памяти; CPU-путь термически неустойчив. Hy-MT2 и TranslateGemma исследованы, но не внедрены; их веса после очистки 13.10 перемещены в Корзину, как и остальные невнедрённые исследовательские модели. [Отчёт](android/benchmarks/2026-10-12-pixel-speed-audit/README.md).
- **Android OPUS Vulkan FP16**: GPU исполняет графы, CPU/GPU greedy parity подтверждён; beam5 на проверенных примерах медленнее CPU в2.5–3.8 раза. Прототип не внедрён. Не сравнивать короткий greedy beam1 с production beam5. [Отчёт](android/benchmarks/2026-10-12-opus-vulkan/README.md).
- **iPhone OPUS CoreML GPU**: отдельный опыт показал1.55–2.30× замедление и новые вставки текста/HTML в2 из4 случаев. Не внедрён. Результаты находятся во внешнем `kat-translation-lab-2026-10-10`, путь приведён в отчёте Mac54/iOS36; этот каталог не входит в экспорт.
- **Index9B MNN/OpenCL**: эксперимент закрыт. На том же тексте Pixel: MNN после прогрева53,2–53,8с; контроль Vulkan/MTP47,5с, безMTP50,9с. Ускорения нет. Временные сборки и конвертированные веса удалены, сохранён [отчёт](android/benchmarks/2026-10-12-index-mnn-opencl/README.md).

## Что ещё не подтверждено

1. Физическая macOS15–26; нижний OS deployment target сам по себе не доказывает все функции.
2. Обобщённое качество всех языков ASR/MT/TTS/OCR, качество длинного разговора, фактическая пригодность каждого голоса. Лицензии моделей различаются; наличие в каталоге не означает пригодность для любого способа публикации.
3. Полная Android/iOS функциональная и визуальная идентичность; полный microphone/ticker preview → native путь Android, весь MMS/языковой набор и реальная сетевая foreground-service передача. Старые открытые пункты [матрицы](android/FEATURE_PARITY.md) сверять с более поздними отчётами.
4. Физическое Android-устройство с16-КБ страницами, более слабые устройства и минимальная RAM для OPUS. Pixel-проверки выполнены на9Pro/API37/16ГБ/4-КБ страницах.
5. Index 2B на Android: скачивание из сети внутри приложения, полная многоязычная приёмка против 9B (проведены только выборочные пробы), устройства без Tensor G4. Устройства без ARMv8.2 dotprod/FP16 получат понятную ошибку Index вместо сбоя — на таком устройстве не проверено.
6. Финальные store/release builds, издатель/контакты, итоговые материалы и публикация. [Комплект подготовки](publication/2026-10-12/README.md).

## Как читать историю

Приоритет: текущий код/каталоги и версия конкретного артефакта → отчёт испытаний именно этой сборки → этот обзор → исторические планы/README. Код доказывает реализацию, но не автоматически успешное аппаратное испытание. `docs/CURRENT_STATE.md` содержит накопленную историю; новые записи могут заменять выводы старых. Число тестов относится к конкретному прогону.


## Хранение сборок и место на диске

Оставляются последние три доступные готовые версии каждой платформы (см. «Артефакты» выше). 13.10 проект очищен: 88 → 64 ГБ. Перемещены в Корзину (`kat-cleanup-2026-10-13`), а не удалены:
- временные сборки;
- рабочая копия весов MLX (опубликована на HF, SHA совпадает);
- старый бэкап Mac 0.6.1;
- результаты UI-тестов;
- невнедрённые исследовательские веса (TranslateGemma, Tower+, Hy-MT2, EuroLLM, NLLB).

Рабочие модели, исходники OPUS-направлений, SDK и окружения сборки не тронуты. [Манифест](maintenance/cleanup-2026-10-13.md); прошлые очистки — [12.10](maintenance/cleanup-2026-10-12.md), [дедупликация](maintenance/dedup-lab-2026-10-12.md).

**Подпись iPhone.** По проверке от 13.10 истёкший development-профиль был причиной «Kat translator is no longer available»; build44 пересобран и установлен по Wi-Fi через `devicectl`, данные сохранены. Использованный новый профиль истекает 20.10. Срок следует проверять у конкретного профиля.
