# Единый выбор распознавания Android — 21 октября 2026

## Изменение

В режиме «Авто» русский использует GigaAM v3 INT8, английский — Parakeet v2 INT8, остальные поддерживаемые языки — Whisper large-v3-turbo Q8. Первичная настройка предлагает те же пакеты. Подготовка модели, предварительные фразы, импорт, запись без предварительной обработки и повторная проверка всей записи используют единый выбор. При отсутствии требуемого пакета приложение предлагает скачать его, а не переключается на другую модель или системный ASR.

Сессия записи закрепляет распознаватель, в том числе для повторной проверки. Явный ручной выбор модели действует согласованно во всех путях. Parakeet v3 и системный ASR больше не являются скрытыми альтернативами автоматического режима; они не удалены из ручного выбора. Описание режима обновлено для RU/EN/ES/TR.

На Pixel сохранён Index 2B Q4_K_M для перевода; убран прежний общий ручной выбор Whisper, включён режим Авто. Выбор переводчика для других установок и начальный режим перевода не менялись. Основное приложение обновляется поверх установленного 0.4.6 (21); это development-проверка, не новая публикация APK.

## Проверки

- До исправления четыре из шести тестов маршрутизации обнаружили неправильный выбор английского, остальных языков, недоступной модели и пакетов первичной настройки.
- Полные Android unit-тесты: 77 app + 66 inference, без ошибок и пропусков. Lint и сборка прошли. Генераторы каталогов/локализации и две проверки документации прошли.
- На Pixel выполнены восемь реальных ASR → Index 2B проходов: RU/EN × импорт, запись без preview, непроверенный финальный фрагмент без готовых фраз, полная повторная проверка с отброшенным предварительным результатом. Распознанные слова совпали с импортом того же PCM; для GigaAM допускаются различия регистра и завершающей пунктуации. Все переводы непустые, итоговый движок — Index 2B.
- Контрольные файлы: публичные FLEURS RU (4,8 с) и LibriSpeech EN (4,4 с). Время ASR для RU: 1,062 / 0,254 / 0,252 / 0,331 с; EN: 0,366 / 0,359 / 0,354 / 0,347 с соответственно. Это функциональный прогон с различной прогретостью, а не сравнительный бенчмарк.
- Для остальных поддерживаемых языков unit-тест проверяет выбор Q8 независимо от порядка каталога. На Pixel дополнительно проверен выбор Q8 для немецкого, согласованность явного ручного Whisper для RU/EN и отсутствие предварительной обработки при явном выборе системного ASR.

Первый запуск device-теста прошёл RU-импорт, затем остановился из-за обращения тестового адаптера к lazy-рекордеру как к обычному полю. Исправлен только адаптер; повторный прогон прошёл полностью за 29,14 с. Финальный APK штатной полной сборки прошёл тот же тест за 30,225 с; SHA-256 установленного APK совпадает с проверенной локальной сборкой.

## Сохранность данных

После обновления совпали SHA-256 всех 1523 сохранённых файлов моделей и метаданных пакетов и 10 файлов истории. Семантически настройки отличаются только удалённым `recognitionModel`: режим `automatic` и переводчик `index2b` уже были сохранены. Остальные пользовательские параметры сохранены, новые модели не скачивались.

После служебных перезапусков на последнем запуске появился защитный маркер незавершённой автозагрузки. Штатная подготовка через кнопку приложения завершилась: предупреждение исчезло, доступна кнопка «Начать запись», служебный маркер удалён. Пользовательский режим автозагрузки не отключался; итоговые настройки снова отличаются только удалённым общим выбором Whisper.

## Границы проверки

Завершение записи проверено подачей готового PCM в тестовый адаптер внутри androidTest. Реальны обработка приложения, ASR и перевод; физический микрофон, AudioRecord, акустика и ticker предварительных фраз в этом прогоне не проверялись. Озвучка выключена. Качество перевода не оценивалось как новый бенчмарк.

Изменения проверены в общем рабочем дереве с ранее существовавшими незавершёнными IndexEngine/IndexTranslateProbe; эти файлы не изменены данной задачей и не входят в её коммит. Новые тестовые модели не загружались. Временный тестовый APK и копии входных файлов удалены после проверки.

Подробные локальные журналы и контрольные суммы находятся в игнорируемом `.build/android-asr-routing-2026-10-21/`; приватные настройки, история и идентификаторы устройства в Git не включаются.
