# Android 0.4.2 (17): автоматический выбор моделей перевода — 13 октября 2026

Требование пользователя: при первом запуске человек не выбирает модели. Он отмечает свои языки (можно несколько) и языки перевода, а приложение само собирает перевод, распознавание и голоса и показывает общий объём. На мощном устройстве приоритет у Index 9B, на слабом (как Pixel) — у OPUS. Дополнительно: короткий тест на устройстве определяет класс и даёт рекомендацию.

## Тест устройства

- `memory_probe.cpp` (в `kat_index`) — устойчивая пропускная способность чтения памяти, 4 потока × 32 МБ, около 1 с, без файлов моделей. Обоснование: генерация Index ограничена памятью (см. [аудит](../2026-10-12-pixel-speed-audit/README.md)).
- Калибровка, оценка Index 9B ≈ 0,8 × пропускная способность / 5,78 ГБ:

| Устройство | Пропускная способность | Измерено (9B) | Оценка |
|---|---|---|---|
| Pixel 9 Pro | 27,7–28,4 ГБ/с | 3,9 ток/с (Vulkan) | 3,8 ток/с |
| Mac M3 Pro (тот же код) | 115 ГБ/с | 23 ток/с | 16 ток/с, консервативно |

- Класс «мощное», если оценка ≥ 8 ток/с и RAM ≥ 11,5 ГБ; иначе «среднее». Результат сохраняется в настройках (`deviceClass`, `deviceBandwidthGbps`). Тест запускается один раз, при первом старте, в рабочем потоке.
- iPhone и Android с другими SoC для калибровки не замерялись.

## Режим «Авто»

- Новое значение `translationModel = "auto"` — по умолчанию для новых установок. Сохранённый выбор пользователя не меняется: на Pixel остаётся его «opus». «Авто» стоит первым пунктом в «Моделях» с пометкой «Рекомендуется».
- Модель выбирается для каждой пары из установленных:
  - мощное устройство: Index 9B → Index 2B;
  - среднее: OPUS (если есть установленное направление для пары) → Index 2B → Index 9B.
- `TranslatorState`: `resolveModel(from, to)`, `effectiveModel`; движок Index перезагружается при смене модели (`engineModel`); подготовка не падает, если подходящая модель не установлена.
- Настройка языков (`PackageLanguageSetup`):
  - «мои языки» можно отметить несколько (`extraPrimaryIds`); пары — каждый свой язык × каждый язык перевода;
  - `AUTO_STRONG`: Index 9B;
  - `AUTO_COMPACT`: OPUS-направления для каждой пары в обе стороны, а для пар без доступного OPUS — Index 2B;
  - распознавание и голоса — как раньше;
  - внизу «Осталось скачать … · всего …»; экран показывает оценку скорости и объясняет выбор.
- Ручной выбор моделей и экран «Направления OPUS» остаются в «Моделях» для продвинутых пользователей.

## Проверки

- 99 JVM-тестов, 0 ошибок. Новые проверки: план для мощного и среднего класса, несколько своих языков, `withActivePair`. Lint — 0 ошибок.
- Pixel 9 Pro: `OpusDefaultFlowTest` (свежий выбор = «Авто», RU→EN через OPUS, затем ручной выбор Index сохраняется после пересоздания) — OK под thermal guard. Тест устройства: 27,7 ГБ/с → «среднее». После теста восстановлены пользовательские настройки (модель «opus»).
- APK `dist/android/kat-translator-0.4.2-debug.apk`, SHA-256 `30fd837a32c652211ab220ec9adaa1fc3503eb3fe84a221997362dd45a5ddce4`. В `dist/android`: 0.4.2, 0.4.1, 0.4.0.

## Ограничения

- Калибровка только по двум устройствам. Порог 8 ток/с — продуктовое допущение.
- Пока OPUS-направления не размещены в сети, на среднем классе большинство пар уйдёт на Index 2B.
- Экран настройки языков на устройстве визуально не проверялся.

## Дополнение: 0.4.3 — тест устройства перед выбором языков (3–5 с, память и GPU)

Уточнение пользователя: тест на 3–5 секунд проверяет и память, и GPU, ничего не скачивает. По результату рекомендуется Index 9B или OPUS + Index 2B; для Android закладывается запас на нагрев. Тест идёт **до выбора языков**, а сам выбор языков обязателен, чтобы не скачивать всё подряд.

- `gpu_probe_matvec.cpp` (`kat_index`): матрица Q4_K умножается на вектор (4 × 8192×8192, ~151 МБ нулевых весов) на том же Vulkan-бэкенде ggml, что использует Index. Это повторяет нагрузку генерации; одна прогревочная итерация, затем 2 с замера. `memory_probe.cpp`: 1,5 с. Итого около 4 с.
- Оценка Index 9B = 0,7 (запас на нагрев) × max(GPU ГБ/с ÷ 5,78; 0,8 × CPU ГБ/с ÷ 5,78). «Мощное» — оценка ≥ 8 ток/с и RAM ≥ 11,5 ГБ. Константы вынесены в `TranslatorState.kt` (`PROBE_*`, `STRONG_TOKENS_PER_SECOND`).
- Pixel 9 Pro: GPU 21,6 ГБ/с → 3,74 ток/с без запаса (измерено 3,9 ток/с, погрешность ≈4%); CPU 26,4 ГБ/с; с запасом 2,6 ток/с → «среднее» → рекомендация OPUS + Index 2B.
- Первый запуск: если ни одна модель перевода не установлена и настройка не завершалась, сразу открывается «Ваши языки».
  - Сверху блок «Проверка устройства»: прогресс, затем результат (память, GPU, оценка с учётом нагрева), рекомендация и кнопка «Проверить снова».
  - Языки показываются только после теста; пока тест идёт, «Скачать» недоступна.
  - «Позже» или начало загрузки отмечают настройку завершённой (`setup.completed`).
- Проверено на Pixel: тест сохранил значения; экран показывает «Память: 26 ГБ/с · GPU: 22 ГБ/с · Index 9B с учётом нагрева…» и рекомендацию OPUS + Index 2B. 99 JVM-тестов, lint 0 ошибок. Автоматическое открытие экрана при первом запуске не проверялось, потому что на Pixel модели уже установлены.
- APK `dist/android/kat-translator-0.4.3-debug.apk`, SHA-256 `f805d8afc81cad416bd4f7b7a0d8f8702997cd03f5f76dd74898569d2896c5ef`. В `dist/android`: 0.4.3, 0.4.2, 0.4.1.
