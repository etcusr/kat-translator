# Android 0.4.0 (15): все направления OPUS-MT Big — 13 октября 2026

Добавлены все доступные модели OPUS-MT Big отдельными пакетами. Позже появится меню, где пользователь отмечает нужные направления, видит общий объём и скачивает всё одной кнопкой. Модели пока хранятся на Mac; качество проверяется на Mac.

## Устройство

- **Один пакет = одно направление модели** (`opus-tc-big-<direction>-int8`, ~235 МБ). Всего 54 направления, 13,1 ГБ. Языки: ar, be, bg, bs, ca, cs, da, de, el, en, es, et, fi, fo, fr, he, hr, hu, is, it, lt, lv, mk, nn, no, pl, pt, ro, ru, sl, sr, sr-Latn, sv, tr, uk. Исходный EN-пакет (`en-zle` + `zle-en`) не менялся.
- Каталог `assets/catalogs/opus-direction-packages.json` создаётся скриптом `scripts/android/generate-opus-pairs-catalog.py`. Для каждого направления указаны языки-источники и цели (id приложения) и маркеры целевого языка из карточек моделей (`>>pol<<`, `>>ukr<<`, `>>fin<<`, `>>por<<`…). Порядок в каталоге задаёт приоритет маршрутов: сначала однопарные модели, потом групповые.
- **Хостинг.** 10 направлений побайтно совпадают с опубликованными конверсиями: NothingSoftware DE/FR/ES→RU и crash-sv EN→ES/FR/IT/PT, FR/IT/CA-ES→EN. Их приложение скачивает из сети. Остальные 44 направления — `HOSTING-PENDING`, только ручная установка.
- **OpusRuntime** (общий файл): новые функции `ot_opus_{count,prepare,run}_direction(context, direction, marker)`. Старые функции с языковой парой оставлены для Apple и работают как раньше (EN-пакет). JNI и `OpusEngine` используют только новые, через `OpusRoute(direction, marker)`.
- **Маршрутизация**: `PackageCatalog.opusRoute(catalog, source, target)` — первый пакет, чьё направление покрывает пару. `TranslatorState`, языковое меню и подсказки (`KatApp`) и план загрузки (`PackageLanguageSetup`) работают по маршрутам. Для языка нужны оба направления: основной язык → язык и обратно.

## Проверки

- 98 JVM-тестов, 0 ошибок (новый тест покрывает маршруты, маркеры, приоритеты и планы); lint — 0 ошибок; Python — 92/92; APK собраны.
- **Качество на Mac.** Каждое направление переводило 3 русских предложения; на другие языки их предварительно перевела Index 9B. Проверялись числа, письменность и смысл на глаз (`quality_opus_all.py`).
  - Большинство направлений без проблем. Числа сохраняются: «07:45 → 7:45» — допустимое расхождение.
  - **Исключены**: EN↔KO (конверсия модели с раздельными словарями выдаёт мусор) и RU→сербский латиницей (ломается диакритика: «kreæe» вместо «kreće»). Латинский сербский остаётся только как язык-источник.
  - Слабые места оставлены и задокументированы:
    - RU→PL потерял дату в одном предложении;
    - CS→BE исказил смысл;
    - лексика «путь/колея» передаётся как «трасса», «круг», «дорога».
- **Pixel 9 Pro, 0.4.0**: функциональная проверка нового маршрутного кода (не замер скорости, по одному проходу).
  - DE-направления установлены по USB с проверкой SHA приложением.
  - Новость RU→DE — 9,7 с, DE→RU — 9,0 с; новость RU→EN — 8,7 с, NASA EN→RU — 48,9 с.
  - Тексты совпадают с 0.3.9: маркеры и старый EN-пакет работают как прежде.
- APK `dist/android/kat-translator-0.4.0-debug.apk`, SHA-256 `bbe04b1b1afd94f08fe1651ac4607d4a1688a473eff02a18108c3056a18ea51a`. Установлен на Pixel, данные сохранены. В `dist/android` — 0.4.0, 0.3.9, 0.3.8.

## Ограничения

- Хостинг 44 направлений не выбран; загрузка из сети для них не проверялась.
- Меню выбора направлений с общим объёмом — следующий шаг. Сейчас каждое направление — отдельная строка пакета в «Моделях», пакетов много.
- Пакеты пар из 0.3.9 (`opus-mt-big-{de,fr,es}-zle-int8`) остались на Pixel как неиспользуемые каталоги, ~1,5 ГБ. Каталог 0.4.0 их больше не знает; удалить их через приложение нельзя.
- Пары X→EN для PT отсутствуют у Helsinki; для языков, у которых есть только одно направление, план загрузки не считается полным.
