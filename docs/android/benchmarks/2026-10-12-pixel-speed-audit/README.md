# Аудит скорости Index на Pixel 9 Pro — 12 октября 2026

Вопрос пользователя: Index 9B на Pixel 9 Pro слишком медленный; есть ли ошибка портирования/конфигурации, и если нет — какая многоязычная модель заметно быстрее.

## Метод

- Отдельные `llama-bench` / `llama-completion` из того же pinned llama.cpp `d812350`, RelWithDebInfo, как APK. В APK не упаковывались; установленное приложение, его модели и данные не менялись. 9B читался из папки приложения только на чтение.
- Варианты CPU-бэкенда: **A** — как в APK до 0.3.8 (`GGML_NATIVE=OFF`, arch не задан → NDK `armv8-a`; CMake-проверки DOTPROD/I8MM/FP16 = Failed); **B** — `armv8.2-a+dotprod+i8mm+fp16`; **C** — B + `GGML_CPU_KLEIDIAI`; **D** — `armv8.2-a+dotprod+fp16`. Vulkan: через `apps/android/.../CMakeLists.txt` с Mali-патчами, production-политика без `KAT_VK_*`, `-ngl 99`, с CPU-флагами A и B.
- Tensor G4 (`/proc/cpuinfo`): asimddp, i8mm, bf16, sve, sve2, svei8mm, svebf16. cpu0–3 A520, 4–6 A720, 7 X4.
- Параметры как в приложении: `-fa 1 -ub 128 -b 512`, 4 потока, `taskset f0` (ядра 4–7), если не указано иное.
- Все принятые цифры прошли неизменённый `thermal_control.py` (G3D 65 °C, кожа 38 °C, батарея 39 °C, троттлинг). Копия скрипта отличалась только разрешённым именем процесса для остановки. Попытка ослабить G3D-лимит для CPU-прогонов была отклонена и не применялась.
- CPU-тесты короткие: отдельный тест на каждый повтор, `--delay 20`, `-lm none --no-warmup`; медианы трёх повторов.

## Термика CPU

9B на CPU t4 разогревает BIG/MID до 92–97 °C за 5–10 с; G3D достигает 65 °C за 21–31 с, хотя GPU простаивает. Полный pp128/pp256+tg64 для 9B на CPU дважды остановлен guard. Полный перевод статьи на CPU (`llama-completion`) остановлен у всех моделей примерно через 10 с (G3D 66–68 °C). Вывод: продолжительный CPU-инференс на этом телефоне упирается в термолимит; продуктовый путь остаётся Vulkan.

## Выводы

1. **Ошибка конфигурации подтверждена**: CPU-бэкенд llama.cpp в APK собирался под базовый `armv8-a`. Флаги dotprod/fp16 дают ×2,4–3,3 на вводе и +15–25% на генерации — только в CPU-режиме. На Vulkan-путь приложения влияния нет (17,5 / 3,9 при A и B).
2. **i8mm не нужен**: D (без i8mm) в пределах шума от B, но совместим с Tensor G1/G2 и Snapdragon 865/888. KleidiAI на Q4_K ничего не добавляет. Q4_0-репак не проверялся: генерация ограничена памятью, кратного ускорения 9B он не даст.
3. **9B упирается в память**: ~4 ток/с на любом бэкенде. Каждый токен читает ~5,8 ГБ весов (≈26 ГБ/с при 4,5 ток/с). Настройками кратно не ускоряется.
4. **Компактные модели**: Index 2B и Hy-MT2-1.8B примерно в 3,5 раза быстрее 9B на той же статье, TranslateGemma-4B — примерно вдвое. Index 2B выбран для интеграции: та же архитектура qwen35, тот же промпт и рантайм, 150 языков. У Hy-MT2 33 языка и другой формат промпта.

Исследовательские веса Hy-MT2-1.8B и TranslateGemma-4B (сообщество mradermacher, условия Gemma) скачаны в `model-store/research`, SHA сверены. В продукт они не добавлены. Сырые логи остались локально в `.build/pixel-speed-audit-2026-10-12/` и в Git не входят.
