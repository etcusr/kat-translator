# Android 0.3.9 (14): OPUS-MT Big пары с русским — 13 октября 2026

Подключены на Android все отдельные пары OPUS-MT Big с русским. Модели RU→X пока хранятся только на Mac, никуда не загружены; на Pixel дополнительно не проверять — скорость ожидается та же, что у OPUS EN↔RU.

## Что добавлено

- Шесть пакетов `opus-mt-big-{de,fr,es,it,pt,fi}-zle-int8`. В каждом оба направления (`X-zle` и `zle-X`), около 490 МБ. Модели Helsinki-NLP `opus-mt-tc-big`, лицензия CC-BY 4.0. Каталог `assets/catalogs/opus-pair-packages.json` создаётся скриптом `scripts/android/generate-opus-pairs-catalog.py` по проверенным локальным файлам `model-store/research/opus-pairs`.
- Откуда скачиваются файлы:
  - DE/FR/ES→RU — опубликованные конверсии NothingSoftware (зафиксированные ревизии). `model.bin` и `.spm` побайтно совпадают с нашей конвертацией `ct2-transformers-converter --quantization int8`.
  - Остальные девять направлений (RU→DE/FR/ES и обе стороны IT/PT/FI) **пока не размещены**: адрес содержит `HOSTING-PENDING`. Приложение помечает такие пакеты «скачивание пока недоступно; установите вручную». Ручная установка проходит через app-owned fixture import с проверкой SHA.
  - После выбора хостинга достаточно перезапустить генератор с реальным `--base`.
- `shared/native/OpusRuntime/OpusRuntime.cpp` (общий для Android и Apple):
  - пакет сам находит подпапки направлений `<a>-<b>`;
  - маркер `>>rus<<`/`>>ukr<<`/`>>bel<<` ставится для любой модели в восточнославянские языки;
  - поведение EN-пакета (`en-zle`/`zle-en`) не изменилось.
  - Apple-рантайм с этим изменением не пересобирался.
- `OpusEngine`: `packages` (язык-партнёр → пакет), `packageFor(source, target)`. Движок привязан к своему пакету.
- `TranslatorState`:
  - переключение пакета по паре;
  - при предзагрузке без нужного пакета прогревается EN-пакет, а сам перевод сообщает, какой пакет установить;
  - `installed` = установлен любой OPUS-пакет.
- UI: OPUS остаётся одним пунктом выбора модели. Пары показаны отдельными пакетами для загрузки. Список языков OPUS расширен, подсказки ограничений обновлены (RU/EN).
- План загрузки (`PackageLanguageSetup`): для OPUS подбирается пакет на каждую пару «основной язык ↔ целевой».
- Тесты:
  - `OpusContractTest` и `PackageLanguageSetupTest` — согласованность каталога и `OpusEngine`, планы для пар;
  - `TranslationArticleSpeedTest` получил `-e partner` и `-e partnerFile`.
- Перегенерированы iOS/Mac-проекты (новый каталог в ресурсах) и снимок состава сборки.

## Проверки

- `scripts/android/build.sh`: 99 JVM-тестов, 0 ошибок; lint — 0 ошибок; debug и androidTest APK собраны. Python — 92/92.
- Качество (Mac, CTranslate2 INT8, beam 5), фразы RU → X и обратный перевод выхода Index 9B через X→RU:
  - DE/FR/ES: близко к 9B и не хуже Index 2B;
  - IT/PT/FI: факты и числа сохранены, но есть лексические промахи. «Третий путь» стал «terceiro caminho» (PT) и «kolmannesta reitistä» (FI). «Я плохо понимаю на слух» переведено неверно в IT/PT и особенно в FI («En ymmärrä huhua»). «Перенесут» в IT стало «si terrà».
  - Если подать два предложения вместе, второе теряется. В приложении текст режется по предложениям (`OpusSegments`).
- Pixel 9 Pro, приложение, DE (одна пара до остановки серии), под thermal guard: новость RU→DE 9,9 с, DE→RU 9,0–9,1 с, загрузка модели 0,2–0,3 с. Это на уровне OPUS EN↔RU (8,6–9,2 с). Пакеты DE/FR/ES были установлены по USB, приложение проверило SHA всех 30 файлов.
- APK `dist/android/kat-translator-0.3.9-debug.apk`, SHA-256 `3bdea33748eb62edcb00a2fa060cb5ac2000f2d0946553c8f8a069dc126b9b19`. Установлен на Pixel поверх 0.3.8, данные сохранены. В `dist/android` хранятся 0.3.9, 0.3.8 и 0.3.7.

## Не сделано / ограничения

- Хостинг файлов, которых нет в сети, и проверка скачивания из сети. Пакеты IT/PT/FI на Pixel не устанавливались и в приложении не проверялись — только на Mac.
- Групповые модели OPUS (RU↔польский/чешский/словацкий, RU↔сербский/хорватский/болгарский/словенский, RU↔шведский/датский/норвежский) требуют маркера целевого языка вне восточнославянской группы и в этот выпуск не вошли.
- Пары EN↔X без русского (например, EN↔DE) не подключались: выбор пакета сейчас строится вокруг RU/UK/BE.
- Регулярное выражение границ предложений не делит перед заглавной буквой с диакритикой (É, Ä, Ñ…), такие предложения могут попасть в один сегмент.
