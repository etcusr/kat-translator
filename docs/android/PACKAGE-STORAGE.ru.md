# Пакеты Android и общие каталоги

[English](PACKAGE-STORAGE.md) | **Русский**

> Техническая справка, написанная на этапе 0.3.x. Начиная с 0.4.x начальный выбор перевода — «Авто» (см. [текущее состояние](../CURRENT_STATE.ru.md)); утверждения ниже, называющие OPUS Big значением по умолчанию на Android, — исторические.

`PackageRepository` создаётся один раз на процесс и принадлежит `PackageDownloads`; его используют ViewModel Android и foreground service. Его `catalog` берётся напрямую из тех же JSON-файлов `assets/catalogs`, что и на Apple. Веса моделей не входят в APK и не копируются в исходные каталоги Android.

`scripts/android/generate-package-capabilities.py --check` сверяет сгенерированные соответствия языков с общими определениями Swift. Сгенерированные метаданные содержат точные коды языков Whisper, Omnilingual и Supertonic и закреплённые дескрипторы Wayu. `android-ocr.json` описывает дополнительный детектор PP-OCR, нужный на Android, где нет Apple Vision. Его закреплённые ревизия, размер и SHA-256 взяты из upstream-дерева Hugging Face LFS.

## Runtime API

Репозиторий предоставляет `catalog`, `states: StateFlow<Map<String, PackageStatus>>`, `start`, `pause`, `cancel`, `remove`, `importFile`, `installedPath` и `file`. `restored` становится true после проверки при запуске. Действия пользователя по загрузке/импорту должны идти через `PackageDownloads`, чтобы Android получил запрос foreground service. `OfflinePackage.backend`, `languages`, `runtimeLanguage` и `unavailableReason` описывают пригодные движки и точные языковые ограничения. Владельцы runtime должны держать аренду `acquire(id)`, пока нативный код читает или отображает пакет в память; удаление отклоняется, пока аренда активна.

`installedPath` возвращает файл весов для Index, Whisper и OCR и каталог для архивных и многочастных пакетов. `files` перечисляет относительные пути внутри каждого каталога. UI не должен делать вывод об установке по наличию файлов.

## Одно хранилище на устройстве

Существовавшая модель Index остаётся в `getExternalFilesDir(null)/Index-Translate-9B.Q4_K_M.gguf`. Остальные установленные файлы и каталоги находятся в `packages/` на том же томе. Для каждого общего голоса — один пакет, сколько бы языков его ни использовали. Файлы токенов, веса, лицензии и вспомогательные файлы принадлежат родительскому пакету. Удаление пакета удаляет все его компоненты.

Загрузки выполняются последовательно; блокировка процесса/файла защищает владение хранилищем. Перед началом приложение проверяет оставшиеся сжатые байты, байты распакованной установки и резерв 128 MiB. Частичные файлы и HTTP ETag переживают завершение процесса. Следующий старт продолжает через HTTP Range/If-Range; если сервер вернул 200 вместо 206, компонент безопасно начинается заново. Сетевые ошибки повторяются дважды. Принимаются только HTTPS, ограниченное число перенаправлений, точные диапазоны и размеры ответа.

Пауза сохраняет частичные файлы; отмена удаляет их. Обе прерывают сетевую работу и проверку. Возобновление может заменить приостановленную операцию даже во время закрытия её сокета; последовательный исполнитель ждёт очистки перед перезапуском. Загрузки/импорт используют foreground service `dataSync` с уведомлениями о прогрессе, действиями паузы/отмены и ограниченным wake lock. Завершение сообщается только после проверки. UI и сервис никогда не открывают вторую блокировку хранилища. Таймаут Android 15+ ставит работу на паузу и сразу останавливает сервис. При завершении процесса частичные файлы остаются докачиваемыми последующим явным действием пользователя; сервис NOT_STICKY.

## Выбор языков и очереди

`PackageLanguageSetup(primaryId, targetIds, recognition, speech).plan(...)` определяет выбранную модель перевода, возможности Whisper/Omnilingual и выбранный голос для каждого языка. OPUS Big тогда был значением по умолчанию на Android (решение пользователя после проверки на Pixel, 12.10.2026); существующий явный выбор сохраняется. OPUS требует доступного runtime и направлений, связанных с английским. Неподдержанные языки ASR/TTS возвращаются отдельно для пояснения в UI; общие многоязычные пакеты не дублируются. `PackageSetupPlan.summary(states)` сообщает общие/оставшиеся байты, проверенную готовность, активную работу и ошибки. `withActivePair` учитывает позднее выбранные языки. `PackageVoiceDownloads.plan` выбирает по одному голосу для каждого поддержанного языка и убирает дубли общих весов для действия «скачать все голоса».
Экран настройки Android сохраняет выбранную пользователем модель перевода, включая Index для русского/английского; при применении настройки он никогда не переключается на OPUS автоматически. Новая установка тогда использовала OPUS; выбор неподдержанной пары сообщает об ограничении, а не меняет движок молча. Index остаётся доступен со своими проверенными весами и путём. В portability-contract.json `primary_translation` обозначает исходный контракт переносимости/весов Index, а `default_translation` — текущее значение по умолчанию продукта Android. Они намеренно разделены.

`PackageDownloads.startAll(context, ids)` отправляет одну команду сервису после консервативной общей предварительной проверки диска; каждый пакет повторно проверяет место перед установкой. `pauseAll` сохраняет частичные файлы очереди; `cancelAll` также удаляет частичные файлы приостановленных пакетов. Перезапуск того же явного плана продолжает его.

`DownloadAccess` хранит `allowCellularDownloads` (по умолчанию false), как настройка на Apple. UI может проверить `networkState`, `requiresConfirmation`, `canDownload` и `maximumDownloadBytes(ids)` репозитория перед показом того же подтверждения загрузки. Это число байтов — верхняя граница, потому что сервер может отклонить Range и прислать часть заново. Полностью закэшированные/установленные пакеты и импорт не требуют запроса разрешения сети.

Каждая операция фиксирует значение настройки. Каждое новое соединение проверяет активную сеть и использует [Network.openConnection](https://developer.android.com/reference/android/net/Network#openConnection(java.net.URL)) Android для привязки соединения, не меняя глобальную маршрутизацию приложения. Цикл чтения тоже проверяет политику, включая изменение стоимости базовой сети VPN. Тарифицируемый Wi-Fi и транспорт с неизвестной стоимостью требуют разрешения; явно нетарифицируемые Wi-Fi или Ethernet разрешены, в том числе VPN с такими свойствами. Офлайн/неизвестное состояние сети нельзя переопределить переключателем сотовой сети. Изменение настройки применяется к следующей операции, как на Apple.

Каждый скачанный/импортированный компонент проверяется по закреплённому размеру и SHA-256. Многочастный импорт принимает по одному компоненту и завершается, когда есть все компоненты. Неизвестные файлы отклоняются. Подготовка метаданных Piper использует общие суффикс/токены метаданных, затем проверяет производные файлы по общему манифесту установки.

Установка архива допускает только обычные файлы и каталоги из манифеста. Абсолютные пути и выход за пределы каталога, символические ссылки, жёсткие ссылки, расширенные заголовки, дубликаты, неизвестные файлы, лишние байты и неверные контрольные суммы отклоняются. Распаковка ограничена длинами из манифеста и 2048 записями архива; контрольная сумма/завершение bzip2 читается до публикации. Проверенные данные атомарно переименовываются на том же томе; квитанции записываются после успешной установки. Существующие установки перехэшируются, если меняются их идентичность или отметки файлов.

## Ограничения платформы

Текущий медиа-runtime Android может использовать Whisper, Sherpa Piper/MMS, Supertonic, Omnilingual и ONNX-модели OCR. Общие веса Core ML Parakeet требуют Apple Core ML; каталог явно направляет пользователей Android к Whisper. Wayu и OPUS-MT включены после приёмочного прогона Pixel build7b: `.build/android-parity-device/opus-wayu-build7b/attempt-1.log` фиксирует два пройденных теста. OPUS проверил 12 хэшей файлов, 8 эталонов токенов Apple, 6 направлений, лимиты, отмену/новый запрос и перезагрузку. Wayu синтезировал 27 000 ненулевых отсчётов при 24 кГц за 6,12 секунды. OmniVoice остаётся недоступен до приёмки на устройстве. Установка пакета никогда не подаётся как доказательство работы недоступного движка.

## Проверка

`PackageSafetyTest` проверяет реальное прерывание и возобновление локальной HTTP-передачи, игнорируемые/неверные диапазоны, паузу, проверку закреплённых дайджеста/длины, выход за пределы каталога в архиве, отклонение ссылок, дубликатов и неизвестных файлов, а также полную загрузку общего каталога. Запуск: `:app:testDebugUnitTest --tests '*PackageSafetyTest'` плюс проверка генератора метаданных. Проверки воспроизведения/распознавания/OCR и жизненного цикла на устройстве — отдельные интеграционные проверки; одна успешная установка пакета не доказывает паритета inference.

`PackageLanguageSetupTest` охватывает дедупликацию общих моделей, необязательные возможности, ограничения OPUS, запасной голос, отсутствующие возможности, частичный/проверенный прогресс и расширение активной языковой пары. `PackageDownloadServiceTest` требует уже установленного пакета OCR (по умолчанию `servicePackageId=ppocr-v5-english`) и уже включённых уведомлений. Он никогда не выдаёт и не отзывает разрешения. При необходимости внешний стенд должен сохранить/выдать/запустить/восстановить разрешение на уведомления, потому что отзыв может убить instrumentation. Его тест жизненного цикла с кэшированными файлами не заменяет проверок на устройстве для паузы активной сети, фоновой передачи и таймаута.

`PackageRepositoryLifecycleTest` содержит четыре изолированных сценария на устройстве. Его внутренний конструктор передаёт одноразовый каталог кэша, два закреплённых синтетических файла (всего 768 KiB) и управляемое HTTPS-соединение на экземпляр. Он никогда не меняет синглтон, системную политику транспорта/безопасности, разрешения или файлы моделей пользователя. Сценарии проверяют заблокированное чтение с немедленными паузой/возобновлением, паузу/возобновление в очереди, точные Range/ETag, удаление под защитой аренды, отмену/перезапуск с нуля, закрытие/открытие с частичным файлом, отклонение изменённого установленного файла и восстановление после неверного дайджеста. Подменяется только соединение; запись на диск, контрольные суммы, квитанции, атомарная публикация и очистка операций в репозитории настоящие. Это тест жизненного цикла репозитория, а не доказательство жизненного цикла foreground service Android.

`DownloadAccessTest` проверяет матрицу сетевых решений и прерывает реальную передачу частичного файла, когда фикстура переключается на сотовую сеть, затем продолжает те же байты после возвращения Wi-Fi. Глобальных исключений cleartext/TLS не настроено.

## Автоматический выбор OCR (Android)

Автоматический OCR на Apple использует определение языка Vision; его открытый запасной PP-OCR принимает явно выбранный русский или английский исходный язык. На Android нет Vision. Автоматический OCR теперь запускает все установленные официальные распознаватели English/Eslav на одинаковых фрагментах детектора — один проход детектора и один распознаватель в памяти за раз. Он никогда не выбирает по порядку каталога, не меняет движок перевода, не скачивает веса и не определяет исходный язык по ID распознавателя. Один установленный распознаватель по-прежнему работает, с видимым уведомлением об охвате. Охват ограничен этими пакетами OCR, а не всеми языками перевода Index.

Уверенность CTC усредняется по выданным непустым токенам (без пустого заполнения и повторов по времени). Разные строки-кандидаты требуют уверенности ≥ 0,85, отрыва ≥ 0,12 и не менее трёх букв/цифр. Задокументированное исключение для удаления покрывает случай, когда распознаватель чужой письменности отбрасывает неподдерживаемые глифы: более уверенный кандидат должен иметь ≥ 0,90, не менее четырёх букв/цифр и как минимум на две больше соперника, а соперник сохраняет не более 75% своих символов и имеет как минимум на 25% большую остаточную неопределённость (1 − средняя уверенность). Одна длина не может победить. Иначе пользователь должен выбрать язык явно или взять более чёткое изображение. Различия только в регистре считаются совпадением; похожие кириллические/латинские символы остаются разными. Совпадающие строки и единственный установленный распознаватель всё равно требуют порога уверенности. Оценки разных моделей — не откалиброванные вероятности языка: эта консервативная эвристика может отклонить верный текст, а уверенные ошибки OCR остаются возможны. Pixel build15 правильно распознал семь сгенерированных фикстур; это ограниченное доказательство на фикстурах, а не общая точность распознавания. Неподдержанные письменности с этими двумя весами надёжно определить нельзя.

Адаптер уверенности есть только на Android (`ocr_scored.c` включает общий runtime), поэтому нативный исходник OCR на Apple и его API не изменились. OCR с явным исходным языком по-прежнему использует исходный путь CTC. Неоднозначные блоки проваливают всю операцию, а не теряют текст молча. `OcrAutoSelectionTest` охватывает победы English/Cyrillic, блоки со смешанной письменностью, независимость от порядка каталога, конфликтующую высокую уверенность, короткие омографы, низкую уверенность, числа, охват одной моделью и подсчёт пустых/повторных токенов CTC.

Pixel build14 выявил регрессию авто-OCR: кириллическое `ПРИВЕТ МИР` получило 0,9394511, а английская модель выдала укороченное `PBET MP` с 0,89183354. Исходная политика только с абсолютным отрывом отклоняла этот верный результат. Исключение для удаления добавляет независимое доказательство охвата содержимого вместо снижения отрыва для всех конкурирующих строк. Это по-прежнему эвристические пороги, а не откалиброванные вероятности языка. Точное наблюдение и контрпримеры с почти равенством/более длинным шумом покрыты unit-тестами. Pixel build15 правильно распознал семь фикстур: одиночные/двойные/смешанные, строчные с засечками и английский моноширинный шрифт. Кириллический моноширинный `Встреча завтра` остался неоднозначным: английская модель выдала `Bctpeua 3abtpa` с 0,8990104, Eslav — правильный текст с 0,88896984. Доказательство: `.build/android-parity-device/default-ocr-build15.log`. Это поддерживаемый запасной путь с явным исходным языком, а не утверждение, что автоматическое распознавание работает для любого шрифта. Рабочие пороги сохранены. Контракт устройства теперь отделяет семь фикстур с точным авто-распознаванием от теста, который требует `Ambiguous` для этого моноширинного изображения и правильный результат Eslav при явном выборе языка. Новая проверка явного запасного пути на устройстве ожидала прогона root build16.
