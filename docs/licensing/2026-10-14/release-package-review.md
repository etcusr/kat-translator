# Лицензионный комплект перед публикацией

**Дополнение 14.10:** [комплект исходников](source-kit.md) закрывает приобретение 605 архивов и 9 файлов, Rust/нативные/Python/Android notices дополнены до 42 документов. Таблицы ниже сохраняют результат предыдущей проверки 38 текстов; текущие проверки и остаток — в новом отчёте.

Проверено 14 октября 2026. **Комплект исправлен, но лицензионная готовность всего выпуска пока не подтверждена.** Проверка охватывает фактические IPA iOS 1.0 (47), распакованный PKG macOS 1.0 (66), новый Android debug 0.4.6 (21), тексты уведомлений и доступные исходные изменения. Хэши, состав Python, медиа и патчи — [машиночитаемый протокол](release-package-review.json). Каталог голосов не изменён.

## Что исправлено и проверено

- Общий комплект расширен с **27 до 38** неизменённых исходных текстов. Добавлены Python 3.11, ONNX Runtime 1.30 с транзитивными уведомлениями, libmpdecimal, liblzma/0BSD, oMLX, tqdm 4.70.1, tokenizers 0.22.2/0.23.3 и SentencePiece Python 0.2.2. Источники и SHA-256 — [manifest](ios-notices/manifest.json). Дополнения помечены как относящиеся к Mac: наличие их в общем ресурсе не означает присутствия всех этих библиотек на iOS/Android.
- В распакованном Mac66 обнаружены **62 экземпляра Python-пакетов**: 56 уже сохраняли license/notice-файлы в `dist-info`; для оставшихся шести экземпляров (tokenizers, SentencePiece, tqdm в двух окружениях) добавлены тексты верхнего уровня. Это не утверждение о полном покрытии всех статически включённых Rust/C/C++ зависимостей.
- iOS/macOS получили офлайн-экран **«Лицензии компонентов»** в разделе конфиденциальности: отдельный документ на компонент, полный текст GPL, ссылка на исходники. Подписи RU/EN/ES/TR. Android ранее не упаковывал общий `ThirdPartyNotices.txt`; добавлено включение через задачу синхронизации ресурсов.
- Добавлена проверка **фактического** файла в `.app`, IPA/APK: `scripts/validation/check_release_notices.py`. Она отклоняет отсутствующий или устаревший файл; одноимённый файл внутри зависимости не считается уведомлением приложения.
- Локальные изменения CTranslate2 и OmniVoice **побайтно совпадают** с опубликованными патчами. Изменение FluidAudio ограничено `Package@swift-6.2.swift`, его воспроизводит имеющийся `prepare-speech-recognition.py`. Эти три изменения не потеряны в ignored vendor-каталогах.
- Свежие сборки iOS Release без подписи, Mac Release и Android debug завершились успешно. В каждой совпадает SHA-256 уведомлений `74e7a749b2ab883289d528fbda9c21928b69c970aea83f86cdb4ac0ee2b7d39c`. Шесть проверок сборки/упаковки notices и две проверки документации прошли. Проверена компиляция общего экрана; ручной проход на устройствах не выполнялся.

Исторические IPA47 и PKG66 **не изменены**: они содержат предыдущие 27 текстов и прежний экран. Принятие Mac66 Apple не подтверждает полноту лицензий. Перед выпуском требуется новый архив с обновлёнными ресурсами и проверка того же файла после экспорта; текущие сборки проверки не загружались и не устанавливались. Данные подключённых телефонов не затрагивались.

## Что требует решения об условиях или правах

1. **GPL и App Store.** У [GPL v3, §§6/10](https://www.gnu.org/licenses/gpl.en.html) есть требования к соответствующим исходникам и запрет дополнительных ограничений. [Standard EULA Apple](https://www.apple.com/legal/internet-services/itunes/dev/stdeula/) ограничивает передачу/распространение; в части копирования и модификации содержит оговорку для открытых компонентов. Эта оговорка сама по себе не доказывает совместимость всей цепочки доставки. Нужна проверка конкретных условий магазина и EULA для этого выпуска; если применимые ограничения конфликтуют, требуется разрешение правообладателей соответствующего GPL-кода либо другой состав/канал. Kat не может выдать исключение за авторов eSpeak. Автоматически менять GPL, объявлять любую GPL-программу запрещённой Apple или считать публикацию исходников достаточной нельзя.
2. **Supertonic 3.** [OpenRAIL-M, §4(a,b), §5 и приложение A](https://huggingface.co/Supertone/supertonic-3/blob/main/LICENSE) требует передать лицензию и закрепить ограничения использования в применимых условиях для последующих пользователей. Текущая ссылка из интерфейса сама по себе этого не подтверждает. Нужны согласованные условия использования этой модели и их показ пользователю; либо иной голосовой пакет. Условия модели должны быть отделены от GPL-кода Kat.
3. **MMS и OmniVoice.** Для весов действует [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/). Бесплатная установка приложения не разрешает автоматически любое коммерческое применение модели. Нужны понятные пользователю ограничения конкретного пакета и атрибуции/указание преобразований; для коммерческого сценария — подходящее разрешение или замена. Каталог пока сохранён.
4. **Голоса с базой Lessac.** Denis и остальные голоса остаются по принятому решению. Скачивание идёт со сторонних серверов; в Git нет этих весов. [Ответ Piper](https://huggingface.co/rhasspy/piper-voices/discussions/105) по-прежнему не подтверждает права из записей Lessac. Для снятия неопределённости нужны условия именно готового checkpoint и базы от уполномоченной стороны либо оценка этой цепочки прав. Это не установленный прямой запрет. Точные пакеты и альтернативы — [отдельный аудит](voice-alternatives.md).
5. **Медиа.** Не найдены подтверждения прав для **30 физических файлов**: 28 в `LoadingAnimations` и ещё MP4/JPG в `CatWizard`. Нужны разрешения на использование в приложении/магазине либо замена на собственную графику, например штатного рисованного кота. `film-drink` дополнительно требует сверки возрастной анкеты. Новые Header/Search Results используют собственную стилистику интерфейса и не включают кадр кота-волшебника; это не решает права на оставшиеся ролики внутри приложения.

Письма авторам/правообладателям не отправлялись; внешние соглашения и анкеты не менялись. Полный юридический допуск к распространению не заявляется.
