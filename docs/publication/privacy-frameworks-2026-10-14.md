# iOS: privacy manifests встроенных библиотек — 14.10.2026

Проверены Python, TranslationRuntime, OmniVoiceRuntime, `_hashlib` и `_ssl`. Добавлены пять отдельных деклараций и воспроизводимый этап упаковки. Свежий Release archive 0.5.16/build46 собран успешно; приложение и все пять изменённых frameworks прошли строгую проверку подписи. Установка на устройства и отправка в магазин не выполнялись.

## Основания деклараций

[Исходные manifests, версии и ссылки на код](../../Dependencies/privacy/ios/README.md).

- **Python 3.13.14 / Python-Apple-support 3.13-b14:** `C617.1` для метаданных собственных файлов; `35F9.1` для таймеров/интервалов. Проверены CPython `posixmodule.c`/`pytime.c`, изолированная инициализация в `WayuFrontend.c` и упакованный Wayu frontend.
- **TranslationRuntime:** `C617.1`. По дизассемблированию `stat`/`fstat` принадлежат включённым cpp-httplib file/mmap/server helpers. Это не доказательство работающего HTTP-сервера или передачи данных; приложение использует локальный runtime. Наличие библиотечного кода отделено от фактического пути вызова.
- **OmniVoiceRuntime:** `C617.1`; подтверждён `fstat` в `gguf-weights.h::gf_load` для размера локальных весов перед mmap, вызовы из codec/TTS loading.
- **`_ssl` / `_hashlib`:** неизменённый официальный manifest OpenSSL 3.0.18, `C617.1`. Версия подтверждена в бинарнике, декларация — в закреплённом upstream-теге. Общий SHA-256 исходного manifest указан рядом с файлами.

Все пять декларируют отсутствие tracking, tracking domains и collected data types для этой интеграции. Это не результат перехвата трафика и не готовый ответ на общую анкету App Privacy.

## Упаковка и проверки

`scripts/install-ios-privacy-manifests.py` вызывается сгенерированным Xcode-проектом **после** Python conversion и Embed Frameworks, **до** подписи приложения. Он проверяет наличие всех пяти frameworks и совместимость существующих деклараций, копирует manifests и повторно подписывает frameworks. Ошибка подписи прерывает сборку. Другая upstream-декларация не перезаписывается молча. Vendor XCFrameworks и их скачанные файлы не изменяются.

Проверено:

- 7 регрессионных тестов упаковки: наличие/содержимое, порядок copy→sign, неизменность бинарных файлов, повторный запуск, unsigned-режим, отсутствующая библиотека, конфликт upstream и ошибка подписи; порядок Xcode-фаз проверяется отдельно внутри набора.
- 10 существующих проверок структуры проектов и согласованности документации — PASS.
- Все пять plist проходят `plutil -lint`.
- Свежий `xcodebuild archive` — **ARCHIVE SUCCEEDED**.
- В архиве **6 manifests**: приложение + пять frameworks; содержимое новых файлов побайтово совпадает с исходниками, `.xctest` отсутствуют.
- `codesign --verify --deep --strict` приложения и отдельные строгие проверки пяти frameworks — PASS с доступом к системному trust store. В sandbox первоначальная проверка вернула `CSSMERR_TP_NOT_TRUSTED`; вне sandbox тот же неизменённый архив прошёл. Повторное ручное исправление подписи архива не требовалось.

Локальные доказательства (ignored): `.build/privacy-frameworks-2026-10-14/`, включая `archive.log`, `archive-audit.json`, `baseline-audit.json`, `sources/`, `Kat46.xcarchive`. Не публиковать сырые логи подписи и содержимое локального окружения.

## Границы результата

В Python остаются импортируемые `statfs`/`fstatfs` стандартных `os.statvfs`/`os.fstatvfs`. В упакованном Wayu-коде вызовов этих обёрток или `shutil.disk_usage` не найдено. Причину проверки места на диске не добавляли без фактического назначения. Swift-проверки места уже покрыты manifest приложения. Принятие этого состава серверной проверкой Apple ещё не подтверждено; при замечании нужно исследовать реальный вызов либо исключать неиспользуемые API при пересборке Python, а не подставлять произвольную причину.

OpenSSL есть в [списке SDK Apple](https://developer.apple.com/support/third-party-SDK-requirements/). Проверенная подпись встроенных frameworks — подпись приложения после упаковки; она не доказывает наличие отдельной подписи исходного SDK его поставщиком. Валидация Apple, App Privacy, сетевой прогон и полный лицензионный комплект остаются отдельными проверками.

Номер версии/build в этой технической проверке не повышался. Установленный build46 и прежние `dist`-артефакты не заменены; новый архив находится отдельно. Новых голосовых/микрофонных тестов на устройствах этот прогон не включает. Mac/Android не изменены.
