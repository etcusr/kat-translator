# iPhone: приёмка сборки без OpenSSL

14 октября 2026. На физическом iPhone проверена iOS **0.5.16/build46**, Bundle ID `app.kattranslator`, после [исключения OpenSSL](ios-openssl-removal-2026-10-14.md). Пять интеграционных тестов прошли без ошибок. После тестов установлена и запущена обычная сборка без тестового модуля; пользовательские данные сохранены.

Всего: **5 тестов, 0 ошибок, 96,442 с**. Тайский синтез использует фактический iOS Python runtime без `_ssl`/`_hashlib`, штатные локальные словари, стили и ONNX-модели. Три короткие фразы дали 43 800 / 42 000 / 21 000 сэмплов; время синтеза — около 1,30 / 1,31 / 0,83 с. Это единичные измерения, не сравнительный бенчмарк.

Загрузки выполнены под уникальными тестовыми идентификаторами: существующие файлы моделей не заменялись. Проверялись реальные источники каталога, без подстановки ответов сети. После проверки тестовые файлы и записи загрузок удалены.

## Очистка и сохранность данных

До установки сохранены история и настройки, снят список файлов контейнера. Сверка выявила побочный эффект тестовой загрузки: изменился служебный `liveDownloadIDs`. В тест добавлено восстановление этого ключа; прежнее значение возвращено из резервной копии. Повторный тест загрузок с исправленной очисткой прошёл: **1 тест, 0 ошибок, 8,451 с**. После него снова установлена обычная сборка и выполнено обратное чтение данных.

Окончательная сверка:

- все **40 исходных настроек** сохранили значения;
- все **68 записей истории** семантически совпадают; SHA-256 **11 файлов истории** совпадают;
- **8 175 существующих файлов моделей и документов**, 29 074 769 684 байта, сохранили пути и размеры; восстанавливаемые verification-cache файлы исключены из этого сравнения;
- тестовых файлов `kat-openssl-probe-*` в контейнере нет.

Проверка путей/размеров моделей не заявляется как новый полный SHA-256-прогон всех весов. SHA-256 заново проверены для скачанных тестом файлов и сохранённых файлов истории.

## Итоговая установка

Установлена обычная сборка из ранее проверенного Release-архива без OpenSSL. Локальная копия: `dist/ios/Kat-translator-0.5.16-build46.app`; предыдущая копия сохранена отдельно в ignored-каталоге проверки. Строгая подпись — PASS; 72 Mach-O-файла без найденных маркеров OpenSSL/связей с libssl/libcrypto, `_ssl` и `_hashlib` отсутствуют, `.xctest` отсутствуют. Обычный запуск на iPhone завершился успешно.

Тесты: `tests/benchmarks/VoiceAutoRoutingIntegrationTests.swift`, opt-in `KAT_VOICE_AUTO_TEST_BUILD=1`. Обычный Xcode-проект восстановлен генератором после подготовки тестов. Нового production-поведения, номера версии, установки на Android/macOS или отправки в App Store эта задача не добавляет.

Локальные доказательства (ignored): `.build/ios-openssl-device-2026-10-14/` — результаты XCTest, журналы сборки/установки, audit JSON, резервные копии и итоговая сверка. Личные данные, идентификатор устройства и сырые логи в Git не включаются.

## Границы проверки

Вход ASR — синтетические аудиофайлы, обрабатываемые на самом iPhone; новый захват через физический микрофон в этом прогоне не выполнялся. Реальный синтез и завершение воспроизведения проверены, субъективная оценка тайского произношения носителем языка не проводилась. Это интеграционные тесты штатных компонентов, а не проверка всех нажатий UI.

Проверены два файла Wayu, а не весь каталог, фоновые загрузки при заблокированном телефоне или все варианты обрыва/возобновления. Перехват сетевого трафика для App Privacy, заполнение экспортной анкеты, визуальная приёмка ES/TR и обработка сборки Apple остаются отдельными задачами. Предыдущие редкие наблюдения аудиовыхода/распознавания не объявляются исправленными только потому, что этот прогон прошёл.
