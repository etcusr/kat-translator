# Kat translator · общий гайдлайн

Версия документа 1.0 · 12 октября 2026 · владелец продукта пока не указан.

## 1. Продукт и правило обещаний

Kat translator — приложение для локального перевода речи, текста и текста на изображениях. Пользователь выбирает языки, скачивает нужные модели, затем переводит без подключения к интернету. Голосовой сценарий основной; текст сохраняет возможность проверить оригинал и исправить ошибки. Распознавание речи → перевод → озвучка — независимые этапы с отдельными моделями.

Пишем «работает офлайн после загрузки нужных пакетов», а не «интернет никогда не нужен». Не обещаем одинаковое качество во всех языках, мгновенную обработку, синхронный перевод разговора, отсутствие нагрева или работу Index на любом телефоне. Количество языков текстового каталога не равно количеству проверенных голосовых направлений. Доступность обозначаем отдельно для ввода, перевода, озвучки и OCR.

Минимум ОС — настройка сборки, не сертификат работоспособности всех устройств. Index требует нескольких гигабайт RAM сверх интерфейса и файлов; ориентир 12 ГБ общей RAM телефона не гарантирует доступный процессу объём. OPUS подходит для компактного набора направлений. Intel Mac, Windows, Linux, iPad, Wear OS и Android TV отдельными выпусками здесь не подтверждены. Для Android системный путь распознавания импортированного PCM требует Android 13+; это не повышает общий minSdk автоматически.

Совместимая Mac-сборка остаётся отдельным установщиком; она не получила новый OPUS GPU из build54. Обе Mac-версии используют один пакет Index MLX; повторное скачивание этих же весов не требуется. DMG/ZIP распространяются вне Mac App Store; готовность к Mac App Store не подтверждена.

Источник: [KatTheme](../../../../shared/apple/Shared/CatProgressDrawing.swift), [Compose UI](../../../../apps/android/app/src/main/java/org/openoffline/translator/android/KatApp.kt). Платформенные поверхности различаются; визуальное сходство не означает идентичный набор токенов.

Правила новых материалов: один основной акцент, много свободного пространства, крупный смысловой заголовок и реальный экран приложения. Акцентный текст использовать на тёмном, для кнопок — тёмный текст на акцентном. Не писать белым по лаймовому. Шрифт интерфейса — системный; в поставляемых макетах системный sans-serif, без включения чужих файлов шрифта. Бренд в обычном тексте — `Kat translator`; знак `kat` не требует менять официальное имя.

Экспортный масштаб: заголовок 64–88 px на холсте 1080 px, подзаголовок 28–36 px, внешнее поле не меньше 56 px. Это правила промоматериалов, не утверждение о текущих размерах SwiftUI. Значок не растягивать и не дорисовывать; вокруг оставить минимум 1/8 его ширины. Не наносить магазинные бейджи до появления реальной ссылки приложения.

Кот — декоративный помощник загрузки, не индикатор гарантированной скорости. Процент отражает реальный объём пакета. Анимации должны иметь статичное состояние для Reduce Motion. Юмор допустим в декоративной графике, но не в переводе, ошибке, разрешении доступа или privacy-тексте. Флаги дополняют название языка, не заменяют его. Статусы различаются текстом/символом, а не только цветом. Целевые размеры интерактивных зон: 44 pt на Apple, 48 dp на Android; соответствие всего текущего UI ещё требует аудита.

| RU | EN | Правило |
|---|---|---|
| Голос | Voice | Запись и перевод речи |
| Текст | Text | Ввод / вставка и перевод |
| Камера | Camera | iPhone / Android |
| Изображение | Image | Mac, файл/буфер/область экрана |
| С языка / На язык | From / To | Языки, не названия движков |
| Подготовить перевод | Prepare translation | Загрузка моделей в RAM, отдельно от скачивания |
| Скачать | Download | Передача пакета из сети |
| Выгрузить | Unload | Освобождение RAM, файлы остаются |
| Удалить | Delete | Удаление файла/записи; последствия явно указаны |
| Автоматически озвучивать | Speak automatically | Не означает непрерывный перевод разговора |
| История | History | Локально сохранённые результаты |

Формула справки функции: действие → результат → условия → ограничение. Пример: «Запишите фразу и остановите запись. Kat распознает речь и переведёт её. Для озвучки скачайте голос выбранного языка». Ошибка: «Не хватает места для модели. Освободите … и повторите загрузку», с реальным требуемым размером. Не подменять понятное действие именем backend.

Названия технических моделей показывать в каталоге и диагностике: iPhone `Index-Translate 9B · MTP2`; Mac `Index-Translate 9B · MLX + MTP2` и `OPUS Big · GPU`; Android `Index-Translate 9B · Vulkan`. MTP в Android проверять по фактическому режиму, не выводить его из одного имени Vulkan. В публикационном тексте технические названия нужны только для объяснения выбора и требований.

## 5. Вся основная функциональность

### Первый запуск и языки

Выбор исходного и целевого языков; подготовка нужных пакетов; отсутствие голоса не должно блокировать текст перевода. Поиск по названию/коду, избранные, смена направления, ограничения выбранной MT-модели. Выбор языка и выбор ASR-движка — разные настройки. На Android «Авто» языка оставлено в тексте; голос и камера требуют явного языка. На Apple автоопределение доступно по текущему маршруту; короткие/смешанные фразы могут определяться неверно. При совпадении обнаруженного и целевого языков исходный текст может возвращаться без MT.

### Голос

Запуск/остановка нажатием либо удержание по настройке; пауза и продолжение; лимит 1–30 минут, стандартно 10; остановка по тишине с настраиваемым интервалом 1–30 секунд, стандартно 4. Android в режиме удержания не завершает запись по тишине до отпускания. При уходе приложения в фон запись прекращается/отменяется в соответствии с реализацией платформы, а не продолжается как скрытая запись.

Обычный путь: остановка → распознавание → перевод → необязательная озвучка. Исходный текст можно сверить, результат скопировать. Оригинальная запись и синтезированный перевод — разные аудиообъекты с разными кнопками. На Apple экспорт оригинала M4A, на Android WAV; отправка через системное меню только по действию пользователя. Сохранение оригинала зависит от настроек истории; исходные PCM для ASR не меняются усилением воспроизведения.

Импорт аудиофайла есть на Mac и Android; предельная длительность 30 минут. На iPhone кнопка импорта не показывается. Mac принимает форматы системного декодера (в том числе WAV/M4A/MP3); Android использует MediaExtractor/MediaCodec. Не обещать произвольный кодек только по расширению файла.

Экспериментальная предварительная обработка во время записи требует совместимой комбинации Whisper+Index и достаточной памяти, выключена по умолчанию. На Android совместная работа живого микрофона и предварительного конвейера не полностью принята. Это не потоковая озвучка поверх речи пользователя. Старые результаты с удалённым Qwen не описывают текущий релиз.

### Текст

Ввод/вставка, перевод, выбор направления, автоопределение исходного текста, копирование, очистка, расширенный просмотр, озвучка при наличии голоса. Длинный вход делится по предложениям/словам с проверкой фактического числа токенов; части и этапы видны в прогрессе. Index: окно 2048 и до 1536 входных токенов на запрос с резервом ответа; это лимит отдельного запроса, не общего документа. OPUS имеет собственный preflight 480 токенов и разбиение. Отмена должна оставлять движок пригодным для следующего перевода.

### Камера и изображения

iPhone: камера, выбор фото, перевод блоков с наложением, сохранение/отправка итогового изображения; Vision для поддерживаемых языков, PP-OCR для резервных путей. Android: Camera2 и галерея, явный язык, bundled ML Kit для поддерживаемых письменностей, PP-OCRv5 mobile для русского. Не заявлять русское OCR через ML Kit. Mac: файл, буфер и захват области экрана вместо камеры; правка текста результата, отправка/сохранение картинки с переводом. Доступ к камере/фото/захвату экрана зависит от разрешения ОС. Работа OCR не подтверждает качество перевода всех надписей.

### Озвучка

Отдельный голос для языка, встроенный образец, загрузка выбранного пакета, автоматическая или ручная озвучка. Пауза/продолжение, стоп, скорости 1×/1,25×/1,5×/2×. Встроенный короткий образец не доказывает, что пакет установлен. Общие многоязычные пакеты скачиваются без дублей. Отсутствие голоса явно обозначается. Лицензия движка не заменяет лицензию конкретных весов голоса.

### История

Независимые настройки текста, аудио и изображений; сроки/количество, открытие, повторное прослушивание, копирование, отправка, удаление записи и очистка. Перевод сохраняется перед необязательным TTS, затем озвучка прикрепляется к той же записи. Настройки сохраняются сразу; очистка по изменённым лимитам отложена до закрытия настроек. История локальная; синхронизация между устройствами не заявлена. Не включать личную историю в скриншоты. Не сохранённую ранее запись восстановить нельзя.

### Модели, память и загрузки

Скачивание с прогрессом и проверкой размера/SHA-256, управление пакетами и выбором; возобновление/пауза зависят от конкретного пути загрузки. Подготовка в RAM и скачивание на диск — разные операции. Автоподготовка при запуске, удержание модели для повторных реплик, ручная выгрузка, режим экономии памяти с компромиссом повторной загрузки. Проверенные квитанции ускоряют повторную проверку уже установленных файлов. iOS виджет/Live Activity загрузок — Apple-функция; Android использует foreground download service/уведомления. Реальная фоновая передача Android остаётся отдельным пунктом приёмки.

### Настройки и диагностика

Интерфейс RU/EN/по системе, режим записи и тишина, автозагрузка, память, голоса, история, анимации, экспериментальная обработка. Времена ASR/OCR, MT, TTS, загрузки и общего вычисления; общее время не включает запись, прослушивание и ожидание пользователя. RAM/CPU/место показываются с платформенной семантикой; CPU не означает загрузку GPU/ANE, свободный запас процесса не равен свободной RAM устройства. Экспорт диагностики выполняется по команде пользователя; обещание отсутствия содержимого надо проверить в финальном бинарнике.

### Только Mac

Пункт в строке меню, горячие клавиши для выделения, буфера и области экрана, целевой язык для быстрых действий; перевод открывается в основном окне Text/Image. Для выделения и захвата могут потребоваться Accessibility/Screen Recording. Самостоятельная установка через DMG/ZIP. Sandbox/публикация Mac App Store — отдельная работа.

Источники функций: [текущее состояние](../../../CURRENT_STATE.md), [Android parity](../../../android/FEATURE_PARITY.md), [Mac](../../../macos/README.md), [Apple UI](../../../../shared/apple/Conversation/ConversationView.swift). Старые утверждения «голос Android ещё не перенесён» и «на iPhone только обработка после Stop» не использовать без оговорок.

## 6. Модели: что используется и почему

| Роль / платформа | Модель и движок | Зачем выбрано / граница |
|---|---|---|
| MT iPhone / Android | Index-Translate 9B, GGUF Q4_K_M ~5,78 ГБ, llama.cpp Metal/Vulkan | Широкий текстовый каталог (150 языков/вариантов); дорого по памяти, не все направления проверены |
| MT Mac | Index MLX affine 4-bit group64 + MTP2, пакет ~5,24 ГБ | Измеренное ускорение на Apple Silicon; конверсия может менять результат |
| MT iPhone / Android / старый Mac | OPUS Big, CTranslate2 INT8 ~492,65 МБ | Компактный профиль English ↔ Russian/Ukrainian/Belarusian, 6 направлений; прямых RU↔UK/BE нет |
| MT современный Mac54 | OPUS Big, PyTorch Metal FP16 beam5, ~965,47 МБ | Изолированный GPU helper; шесть направлений приняты, выигрыш нельзя переносить на телефоны |
| ASR Apple | Whisper large-v3-turbo F16, whisper.cpp, ~1,62 ГБ | Широкий охват; классический путь; может быть медленным/тяжёлым |
| ASR Apple опция | Parakeet Ultra Core ML, 25 языков, ~632,17 МБ | Альтернативный локальный движок; выбор/доступность зависят от пакета и preference |
| ASR вне Whisper-набора | Meta Omnilingual 300M через локальный runtime | Расширяет доступные языки; наличие upstream языка не доказывает принятую работу на телефоне |
| ASR Android RU Auto | GigaAM v3 INT8, sherpa/ORT ~229,34 МБ | Сохраняет полноту длинной записи, на которой системный путь терял фразы |
| ASR Android другие 24 языка Parakeet | Parakeet TDT v3 INT8 ~670,48 МБ | Единый многоязычный пакет; RU маршрутизируется в GigaAM; физически проверены RU/EN |
| ASR Android прочие/ручной выбор | On-device Android service, Whisper, Meta | Явные альтернативы; не скрытая облачная подмена |
| TTS | Piper (разные голоса), Supertonic 3 INT8 (~128,77 МБ), Wayu Kokoro Thai (~332 МБ), MMS и OmniVoice Q8 (~945,28 МБ) | Выбор тембра/языка и общий пакет; MMS/OmniVoice имеют NC-ограничения, нельзя считать весь каталог коммерчески разрешённым |
| OCR Apple | Vision + PP-OCRv5/ONNX | Системная инфраструктура OCR плюс локальный резерв |
| OCR Android | Bundled ML Kit + PP-OCRv5 mobile/eslav | Разные письменности; русский отдельным открытым маршрутом |
| Определение языка / речь | Apple fastText lid.176.ftz; Android TextClassifier; Silero VAD | Локальное определение текста и границ речи; это не MT-модели |

Текущий Apple-путь Auto получает основной пакет Whisper (`primaryRecognition`); для языков без Whisper-кода используется предусмотренный Meta-маршрут. Parakeet Ultra выбирается отдельно. Это не Android Auto, где русский направляется в GigaAM, а остальные24 языка Parakeet — в Parakeet.

Выбор здесь объясняется архитектурой и существующими испытаниями, а не независимым рейтингом качества. Полный машиночитаемый [реестр пакетов](../evidence/model-inventory.csv) извлечён из каталогов: точные байты, ссылки, объявленные лицензии. Размер скачивания, размер распаковки и RAM не взаимозаменяемы.

TranslateGemma, MiLMMT-46 и Qwen3.5 удалены из пользовательского выбора; Qwen3-ASR, новые GPU-прототипы и исследовательские модели нельзя включать в список поставляемых функций. Архитектурная независимость моделей не означает отсутствие платформенных API: Core ML, Vision, ML Kit и опциональный Android ASR реально используются.

## 7. Как обновлять этот документ

При выпуске сверить plist/Gradle, отчёт установки, каталог и hashes; обновить таблицу платформ. Для оптимизации указать устройство, модель/квантование, corpus, warm/cold, включённые этапы, повторы, качество и ограничения. Для нового языка отдельно подтвердить ASR/MT/TTS/OCR. Скриншотам присвоить версию, локаль и источник. После изменения истории, сети или SDK обновить privacy-текст и магазинные декларации. Ссылки на старые испытания сохранять с датой, не выдавать за новый прогон.
