# Kat translator · комплект публикации

> Это зафиксированный публикационный снимок, подготовленный до Android0.3.7: Android0.3.6 в материалах соответствует моменту их подготовки. Файлы комплекта и ранее созданный ZIP не переизданы этой сверкой. Текущие версии и последующие изменения — в [CURRENT_STATE](../../CURRENT_STATE.md); перед публикацией обновить материалы и финальные снимки экрана.

Срез репозитория: 12 октября 2026. Языки материалов: русский и английский.

- [Подготовка публикации](guide/RELEASE-CHECKLIST.md): обязательные сведения, права, privacy, сборки и приёмка.

**Статус:** комплект для проверки и подготовки релиза. Публикация в магазинах не выполнялась. Данные издателя пока не выбраны. Debug APK и существующий Mac DMG не являются готовыми магазинными сборками. Исторические снимки явно отмечаются в media manifest; их нужно переснять на финальной сборке перед загрузкой. Учебный ролик — отдельный обучающий материал, не автоматическое подтверждение соответствия Apple App Preview.

При противоречии старых README актуальнее текущие исходники и датированные отчёты выпуска. В этом комплекте тесты не запускались заново: приведены ссылки на существующие результаты; отдельно проверены сами подготовленные материалы.

Откройте `index.html` для просмотра всех материалов. Полные журналы тестов и исходники по относительным ссылкам доступны в исходном репозитории; архив содержит сам комплект, а не модели и весь репозиторий.
