# Локализованные скриншоты iPhone: RU / EN / ES / TR

14 октября 2026. **Готовы 16 новых реальных скриншотов iOS 1.0 (49): по четыре для RU, EN, ES и TR.** Сценарий на подключённом iPhone прошёл: один тест, ноль ошибок, 284.654 секунды. В App Store Connect изображения ещё не загружены.

Тексты карточек готовы отдельно: [локализации и ограничения](2026-10-14/LOCALIZATIONS.md). [JSON-манифест кадров](localized-ios-screenshots-2026-10-14.json) содержит относительные пути, язык, экран, версию, размеры и SHA-256. Изображения находятся локально в `dist/store/localized-2026-10-14/ios/{ru,en,es,tr}/screenshots/`, рядом с `metadata/`; `dist` в Git не включается.

## Состав

| Файл в каждом языковом каталоге | Содержание |
|---|---|
| `store-ios-<язык>-1-text.png` | Реальный перевод нейтральной фразы RU→EN |
| `store-ios-<язык>-2-voice.png` | Подготовленный голосовой экран, готовность к записи |
| `store-ios-<язык>-3-models.png` | Модели и режим Авто |
| `store-ios-<язык>-4-languages.png` | Выбор языков и настройка загрузок |

Язык интерфейса меняется независимо от языков перевода. Во всех локализациях используется один и тот же синтетический пример; личные тексты и история не открывались. Голосовые кадры не являются доказательством нового захвата микрофоном.

Все PNG — **1206×2622, RGB, 8 бит, без alpha**. Размер соответствует [спецификации Apple](https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications), проверенной 14.10.2026. Исходные кадры экспортированы из XCUITest attachments побайтово и сохранены отдельно в `dist/store/source-captures-2026-10-14/ios/{ru,en,es,tr}/`; они не входят в готовые каталоги `screenshots` или галерею. Из всех 16 готовых изображений удалена системная статусная полоса: обрезаны верхние **168 пикселей**, оставшаяся область **1206×2454** перенесена вверх без масштабирования, снизу добавлены **168 чёрных строк**. Холст остался **1206×2622**. Граница обрезки проходит по чёрной области до элементов приложения.

Проверено точное равенство каждого сохранённого RGB-пикселя соответствующему пикселю исходника и полностью чёрное заполнение снизу. PNG остаются RGB, 8 бит, без alpha; исходные цветовые метаданные сохранены. Интерфейс не перерисовывался, перевод не подменялся. Все обработанные кадры декодированы и просмотрены; проверены язык интерфейса, отсутствие системных диалогов и статусной полосы, читаемость и сохранность элементов. SHA-256 исходников и подготовленных файлов записаны отдельно в манифесте.

## Выполненный сценарий и сохранность

`TranslatorUITests.testStoreScreenshotsAllLanguages` последовательно снимает четыре языка. Сохранение текста временно выключается настоящим переключателем и восстанавливается после каждого языка. Остальные параметры съёмки задаются в argument domain; модели не скачиваются и не удаляются.

Перед успешным прогоном сохранены настройки и история, после него выполнено сравнение: **настройки совпадают, состав файлов истории и их байты совпадают**. Затем приложение нормально запущено без временных языковых аргументов. Профиль диагностики устройства не изменялся.

Сборка для съёмки — development-signed Release **1.0 (49)**, установленная поверх прежнего приложения без удаления контейнера. Это не TestFlight-приёмка и не отдельное испытание магазинного IPA.

Первые попытки остановились до входа в тестовый метод: `Timed out while enabling automation mode`. После ввода владельцем кода непосредственно на iPhone для **XCTest / Enable UI Automation** повтор прошёл полностью. Изображение системного запроса не включено в комплект.

Локальные результаты: `.build/store-localized-2026-10-14/ios-capture-authorized.xcresult`, экспорт `ios-authorized-attachments`, контрольные копии, `ios-preservation-authorized-summary.json` и `ios-system-bar-crop/validation.json`. Они могут содержать служебные сведения устройства и не публикуются.

## Повторение

Запускать с `TEST_RUNNER_KAT_IOS_STORE_SHOTS=1`, обычным iOS-проектом, Release, подключённым физическим iPhone и отдельным `resultBundlePath`; выбрать только `TranslatorUITests/TranslatorUITests/testStoreScreenshotsAllLanguages`. Для уже собранного runner подходит `test-without-building`. Системное подтверждение автоматизации выполняет владелец устройства.

Перед запуском сохранить настройки и историю; после проверить их содержимое. Экспортировать именованные `store-ios-*` attachments через `xcresulttool export attachments`, проверить каждый кадр и SHA-256. Для текущего подготовленного комплекта повторить описанную обрезку системной полосы с чёрным заполнением; исходники хранить отдельно. Не заменять снимки старых сборок новыми без отдельного каталога.
