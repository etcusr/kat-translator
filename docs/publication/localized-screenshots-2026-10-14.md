# Локализованные скриншоты: RU / EN / ES / TR

14 октября 2026. Текущий статус: **сценарии съёмки подготовлены и скомпилированы, новый полный комплект пока не получен**. Системное подтверждение автоматизации блокирует выполнение сценариев. Старые изображения не выдаются за новые; в App Store Connect ничего не загружено.

Тексты карточек готовы отдельно: [локализации и ограничения](2026-10-14/LOCALIZATIONS.md). Целевое размещение новых снимков — `dist/store/localized-2026-10-14/{ios,macos}/{ru,en,es,tr}/screenshots/`, рядом с `metadata/`. Каталог `dist` локальный и в Git не включается.

## Что подготовлено

- iOS: `TranslatorUITests.testStoreScreenshotsAllLanguages` последовательно снимает RU/EN/ES/TR: реальный перевод, подготовленный голосовой экран, модели, выбор языков. Сохранение текста временно выключается настоящим переключателем и восстанавливается после каждого языка. Перевод в сценарии RU→EN; язык интерфейса меняется независимо.
- Mac: `MacUITests.testStoreScreenshotsAllLanguages` использует текущую проверочную сборку, четыре языка интерфейса и локализованные нейтральные фразы. Порядок — перевод, голос, модели, языки и, если доступна кнопка, направления OPUS. Сохранение текста отключается типизированным переключателем; прежнее состояние и буфер обмена восстанавливаются. Переопределение языка или пути приложения для отдельного прогона сохранено.
- Оба сценария требуют явного opt-in. Языковые параметры запуска не записываются как постоянная настройка. Сценарии не скачивают и не удаляют модели, не снимают личную историю, не записывают микрофон.

## Что фактически проверено

**iOS 1.0 (49)**: Release-приложение и UI runner собраны; приложение установлено поверх прежней 1.0 (47), без удаления контейнера. Две попытки завершились до входа в тестовый метод: `Timed out while enabling automation mode`. Прямая проверка после запуска Kat показала системный запрос **Enter iPhone Passcode for “XCTest” / Enable UI Automation**. Код вводится владельцем непосредственно на устройстве. Этот системный экран не является магазинным скриншотом и в комплект не включён.

**Mac 0.6.7 (60), текущие исходники**: Release-приложение и UI runner собраны отдельно. Установленная копия в `/Applications` не заменена; она содержит только RU/EN и для ES/TR не подходит. Строгая глубокая проверка подписи новой проверочной копии прошла. Обычный и последовательный повтор UI runner завершились до тестового метода с тем же тайм-аутом автоматизации. Запасной захват только окна Kat через ScreenCaptureKit отклонён системной защитой: `SCStreamErrorDomain -3801`. Разрешения не сбрасывались и не обходились. Это не проверка магазинного PKG и не приёмка Mac68.

Свежих пригодных для магазина изображений: **0**. Подтверждение на iPhone ожидается; полный сценарий после него ещё требуется выполнить. Для Mac требуется действующее системное разрешение соответствующему средству съёмки/автоматизации.

## Сохранность данных

- iPhone: перед запуском сохранены настройки и история. После попыток настройки и хэши файлов истории совпадают с исходным состоянием.
- Mac: до запуска сохранены настройки и хэши файлов истории. После временного запуска изменилось положение/размер окна; соответствующий ключ восстановлен, весь словарь настроек совпадает с исходным. Состав файлов истории и хэш медиа совпадают.
- Mac `history.json` после обычного запуска приложения получил другой байтовый хэш. Текущий `setPolicy` всегда выполняет `prune` с повторным `JSONEncoder`-сохранением. Новые переводы в этом проходе не выполнялись. Первоначальная проверка сохранила только хэши, поэтому полное семантическое равенство индекса **не доказано**. После запуска дополнительно сохранена полная копия для последующих сравнений. История вручную не изменялась и не удалялась.

Локальные журналы, результаты сборки и проверки сохранности: `.build/store-localized-2026-10-14/`. Они могут содержать служебные сведения устройств и не публикуются.

## Формат и завершение

По проверенной [спецификации Apple](https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications), iPhone принимает нативные 1206×2622; Mac — 16:10, в том числе 1440×900 и 2880×1800. Прозрачность не допускается. Планируется экспорт настоящих кадров без перерисовки интерфейса и искусственного изменения результата перевода.

После подтверждения автоматизации нужно:

1. Повторить opt-in сценарии для всех четырёх языков; экспортировать именованные attachments через `xcresulttool export attachments`.
2. Проверить каждый кадр: язык, отсутствие системных окон/личных данных, размеры, отсутствие alpha, содержимое и перевод. Сохранить хэши и разложить по языковым каталогам.
3. Повторно сверить настройки и историю, восстановить параметры, изменённые съёмкой. Отдельно запустить обычное приложение с сохранённым языком пользователя.
4. Проверить изображения в App Store Connect Preview и сохранить локализованные карточки. Это ещё не выполнено.

Исторические материалы остаются на прежних местах: [RU build46](ios-store-screenshots-2026-10-14.md), [RU и ES/TR build47](ios-release-preflight-2026-10-14.md). Они не подтверждают завершение этого прогона.
