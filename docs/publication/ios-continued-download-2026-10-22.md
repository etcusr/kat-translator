# iOS: непрерывный прогресс и отмена общей загрузки

## Изменение

Тестовая iOS **1.0.1 (59)** добавляет системную `BGContinuedProcessingTask` для начатой пользователем загрузки на iOS 26+. Запрос использует CPU/network, стратегию немедленного отказа вместо очереди и один индикатор на группу файлов. Если система не предоставляет задачу или версия iOS старше, остаётся прежний путь URLSession + ActivityKit. Это улучшение не обещает неограниченную работу в фоне: iOS по-прежнему может остановить задачу при нехватке ресурсов.

Системная кнопка остановки **приостанавливает** загрузку и сохраняет возможность продолжения. Отдельная кнопка **«Отменить всё»** в Kat требует подтверждения и удаляет готовые и незавершённые файлы только текущей общей загрузки. Перечень файлов, отсутствовавших перед её началом, хранится между паузами и перезапусками. Ранее установленные модели, голоса и общие компоненты защищены. Обычное обновление приложения не вызывает эту очистку.

Частично собранный пакет очищается без удаления ранее существовавших исходных компонентов. Перед удалением останавливаются очереди, проверка файлов и сборка пакетов. Отмена приостановленного URLSession-задания передаёт непрозрачные resume data обратно URLSession и отменяет созданную задачу без её запуска; удаление одной квитанции оставляло многогигабайтный системный временный файл.

## Устройство и метод

iPhone 17 Pro, iOS 27.0.1. Владелец сам удалил магазинную версию до установки прототипа; это **не** тест миграции из App Store. Дальнейшие варианты 59 устанавливались поверх тестовой Kat без удаления контейнера. Для длительного прогона и отмены приложение запускалось обычным способом, без отладчика; отдельный XCTest UI runner активировал Kat, нажимал кнопки и снимал SpringBoard. Для коротких проверок тот же runner запускал специальный вариант с флагом DOWNLOAD_VALIDATION; результат считывался из JSON внутри контейнера. Проверки не используют воспроизведение звука.

Предыдущий диагноз App Store 58: [приостановка процесса и скачки после завершения пакетов](ios-download-freeze-2026-10-21.md).

## Проверенные сценарии

1. **Непрерывный фон:** после Home автоматически зафиксированы проценты 2, 5, 7, 9, 12, 14, 17, 19, 22, 24, 26, 28 с интервалами примерно 15 секунд. Kat не открывалась три минуты. Затем системный индикатор показывал 43%; системная остановка оставила Index в состоянии `paused` с resume data. На прежних проблемных отметках 12% и 31% остановки не наблюдалось. Проценты взяты из дочернего текущего текста индикатора; объединённая accessibility-подпись контейнера иногда отставала на одно обновление.
2. **Отмена готового и незавершённого:** при сохранённых Whisper Q8 и двух RU/EN голосах добавлен испанский язык (общий пакет Supertonic 3). Supertonic успел скачаться и распаковаться; Index оставался незавершённым. Отказ в подтверждении сохранил загрузку. Подтверждение удалило Supertonic, его распакованную папку, resume data и системный временный файл Index. Первоначальный вариант оставил временный файл на 5,3 ГБ; после исправления повторная проверка подтвердила его удаление. Для повторной проверки возвращена только ранее сохранённая служебная квитанция тестового незавершённого Index; её содержимое не использовалось для перевода.
3. **Сохранность:** все 732 ранее существовавших файла моделей/голосов остались. 727 побайтово совпали. У пяти `.verified.json` изменились только поля времени изменения файлов (`changedSeconds`, `changedNanos`) после установки новой сборки; идентичность моделей, inode, размер и время содержимого совпали. Все веса и звуковые ресурсы побайтово неизменны.
4. **Завершение в фоне:** длительный повтор на полном Index остановлен по просьбе владельца из-за нагрева; недокачанный файл удалён через подтверждённую отмену. Диагностический набор из двух компонентов Parakeet общим объёмом 36 247 756 байт завершился в фоне: оба файла проверены SHA-256, pause/resume сохранили прогресс, системная задача начала и завершила выполнение. Это проверка загрузки компонентов, не установка полной модели ASR. Первоначальная UI-проверка не нашла скрытую метку завершения и завершилась ошибкой; успешное завершение подтверждено сохранённым отчётом приложения, а не статусом UI-теста. Последующие проверки не требуют загрузки многогигабайтных моделей.

5. **Небольшой голос:** Denis (67 190 991 байт) + компонент Parakeet (12 642 764 байта), всего 79 833 755 байт. Полученные, ожидаемые и фактические размеры совпали; оба файла прошли SHA-256, завершение произошло в фоне, пауза/продолжение сохранили прогресс, системная задача завершилась. Это проверка загрузчика архива голоса, не качества озвучки. Первый вариант сценария переиспользовал тестовые ID Parakeet и старый ожидаемый размер; он исключён из доказательств. Финальный прогон использует отдельные ID голоса и проверяет реальные размеры.

После очистки диагностических файлов обычная **1.0.1 (59), `ios-7bb43c40cf4734f7`**, установлена поверх тестовой и запущена без диагностического окружения. Все 732 прежних файла остались; файлов `resume.data` и системных `.tmp` нет. В списке языков сохранены RU → EN, текущая группа загрузки пустая, автопродолжение выключено. Отдельный UI runner удалён. Краткие машинные результаты: [JSON](ios-download-checks-2026-10-22.json).

## Автоматические проверки

- 163 проверки Python: passed, включая реальный код менеджера системной задачи с управляемыми API-двойниками, прежний ActivityKit fallback и исправление отмены paused transfer.
- OfflineCore: 347 тестов, 3 skipped, 0 failures; включая сохранение принадлежности завершённых файлов текущей группе и защиту ранее установленных общих компонентов.
- Сборки Release iOS и macOS прошли. Общий интерфейс отмены компилируется на обеих платформах; установлен и проверен на устройстве только iOS.

API-двойники не моделируют реальную приостановку iOS; она проверяется отдельными измерениями устройства. Отдельного физического прогона iOS 18–25/26 нет. Публикации в App Store и push нет; macOS не устанавливалась.
