# iOS: исключение неиспользуемого OpenSSL

14 октября 2026. Проверяется iOS 0.5.16/build46; версия и установленные приложения не менялись. macOS использует отдельный Python 3.11 runtime и в эту проверку не входит.

## Вывод и назначение библиотек

OpenSSL 3.0.18 находился в двух расширениях поставляемого Python 3.13.14: `_ssl` и `_hashlib`. В исходном IPA из предыдущего прогона признаки реализации найдены только в этих двух из 74 Mach-O-файлов. Они исключены из упаковки iOS; функциональные пути приложения не требуют этих расширений:

- Загрузки моделей выполняет `shared/apple/Models/ModelDownloader.swift` через Foundation URLSession. Проверку SHA-256 выполняют ModelStore, PackageStore и PackageArchive из OfflineCore через CryptoKit.
- Python инициализируется изолированно в `shared/native/app/Speech/WayuFrontend.c`, без site-packages. Используется локальный Wayu frontend: тайская фонемизация, английский словарь, токены и чтение стилей из NPZ. Корпуса поставляются с приложением; включены offline/read-only режимы PyThaiNLP.
- В PyThaiNLP есть отдельный код загрузки корпусов с `urllib`/`hashlib`, но он не входит в проверенные пути локального frontend. Тесты запрещают сетевые обращения и импорт OpenSSL, а не полагаются только на переменные окружения.
- `hashlib` сохраняет встроенные реализации `_md5`, `_sha1`, `_sha2`, `_sha3`, `_blake2`; OpenSSL-only функции вроде `scrypt`/`pbkdf2_hmac` этому frontend не нужны. Python `ssl`/HTTPS в урезанной поставке недоступен. При добавлении новых Python-функций это ограничение нужно учитывать.
- TranslationRuntime уже собирается с `LLAMA_OPENSSL=OFF` и `LLAMA_CURL=OFF`. ASR, другие TTS, перевод, OCR и нативные загрузки этим изменением не переписаны.

## Изменение упаковки

`scripts/bundle-wayu-python.sh` сначала вызывает vendor `install_stdlib`, затем собственный `scripts/prune-ios-python.py`, затем vendor `process_dylibs`. Удаляются только копии `_ssl`/`_hashlib` в создаваемом приложении: `.so`, `.fwork`, декларации расширений и оставшиеся frameworks от предыдущей сборки. Проверяется размещение внутри app bundle; неизвестная структура стандартной библиотеки завершает сборку ошибкой. Исходный XCFramework и закреплённый архив Python не редактируются.

Неиспользуемые декларации `_ssl`/`_hashlib` удалены из `Dependencies/privacy/ios/`; упаковщик manifests теперь обслуживает Python, TranslationRuntime и OmniVoiceRuntime. Ожидаемый состав — четыре manifests: приложение и три frameworks. [Предыдущий отчёт о пяти библиотеках](privacy-frameworks-2026-10-14.md) сохранён как исторический.

## Проверки

- **11 тестов упаковки — PASS:** удаление из чистой копии и повторной сборки, сохранение встроенных хеш-модулей, отказ при неверном пути, установка/повторная подпись manifests и обработка ошибок.
- **10 проверок структуры проектов и документации — PASS.**
- **OfflineCore: 272 теста, 2 пропуска, 0 ошибок.** Пропуски относятся к отдельно включаемым тестам скачанных голосовых fixtures.
- **10 тестов упакованного Wayu — PASS** на host Python 3.14 с запрещёнными `_ssl`, `_hashlib`, сетью и запуском дочерних процессов. Проверены тайское произношение, числа, английские вставки, неизвестные слова, границы, токены, сжатый NPZ, четыре позиции настоящего `f_mid_clear` и известные значения хешей. Использован `hashlib.py` из поставляемого Python 3.13 с встроенными расширениями host Python. Это проверка путей Python-кода, а не запуск iOS-бинарников на Mac.
- **Свежий Release archive — PASS.** Проверены все 72 Mach-O-файла: известных маркеров реализации OpenSSL и зависимостей `libssl`/`libcrypto` не найдено; оба исключённых модуля отсутствуют, пять встроенных хеш-модулей присутствуют. Та же проверка правильно отвергает предыдущий IPA с `_ssl`.

Свежий App Store IPA экспортирован **локально**, без upload: **EXPORT SUCCEEDED**. Повторная проверка 72 бинарных файлов также не нашла OpenSSL; четыре manifests побайтово совпадают с исходниками. Строгая подпись приложения и трёх frameworks проходит; distribution-профиль без устройств и `get-task-allow`, тестовых bundles нет. Размер IPA — **68 175 004 байта**, SHA-256 `cfd4964077395bfd07d466d1dc3dae20decb5fc7ce24912635dfaf148c14b35e`. Два удалённых frameworks занимали 6 605 920 байт до сжатия.

Закреплённый исходный архив Python сохранил SHA-256 `8b5cb76ef8d8a2946052479358eeec9d54b4496cb60920e175ec1489b5cf7963`. Подпись архива также проверена отдельно; все четыре декларации совпадают с исходниками. Номер build46 использован только для локальной технической проверки; перед доставкой в магазин нужен согласованный номер выпуска.

Локальные доказательства находятся в ignored `.build/ios-openssl-removal-2026-10-14/`. Сырые логи подписи и параметры локального окружения не входят в публичный отчёт.

Воспроизведение основных проверок:

```sh
python3 -m unittest discover -s scripts/validation -p 'test_ios_*.py'
python3 -m unittest scripts.validation.test_repository_layout scripts.validation.test_docs_app_parity
swift test --package-path shared/packages/OfflineCore
python3 scripts/validation/check_ios_openssl.py /path/to/OfflineTranslator.app
python3 -B -I -S scripts/validation/check_wayu_without_openssl.py /path/to/OfflineTranslator.app model-store/downloads/wayu/voicepacks.npz
```

Последний тест требует подготовленного локального голосового пакета. Без второго аргумента проверка скачанного пакета явно пропускается, синтетический NPZ проверяется всегда.

## Границы

iOS Simulator runtime на этом Mac отсутствует. Новая сборка на iPhone не устанавливалась, реальный звук, микрофон и сетевой трафик на устройстве заново не проверялись. До выпуска нужна приёмка окончательной сборки на устройстве, особенно тайского голоса и загрузки моделей.

Удаление встроенного OpenSSL меняет технические основания экспортной анкеты iOS. Анкета App Store Connect в этой задаче не изменялась; отсутствие этих двух модулей не является самостоятельным юридическим заключением или проверкой macOS. Вопросы Python disk-space API и серверной приёмки manifests Apple остаются из предыдущего отчёта. Старые `dist`-артефакты и установленный build46 по-прежнему имеют прежний состав.
