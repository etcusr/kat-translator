# Kat: Header и Search Results

14 октября 2026. Два отдельных PNG готовы для ручной загрузки в App Store Connect:

| Вкладка | Файл | Размер |
|---|---|---|
| Header | [kat-header-3840x1646.png](kat-header-3840x1646.png) | 3840 × 1646 |
| Search Results | [kat-search-results-3840x2560.png](kat-search-results-3840x2560.png) | 3840 × 2560 |

Оба файла RGB, sRGB, без alpha. Проверены PNG-заголовки, размеры и профиль, изображения просмотрены. Файлы независимы: переключатель **Use header asset in search results** не используется. В разделе **Header and Search Results** загрузить каждый файл в одноимённую вкладку и проверить **Preview** для доступных устройств/ориентаций. Это не обычные скриншоты. Загрузка в кабинет и фактическое отображение в Preview в этой задаче не выполнялись.

Композиция: существующий лаймовый кот Kat, тёмный фон, две реплики «Привет» ↔ «Hello» и звуковая волна. Двуязычная пара показывает пример перевода; интерфейс приложения не имитируется. Название бренда неизменно. Для RU-карточки готово; отдельные EN/ES/TR варианты с локальными примерами пока не подготовлены.

Создано встроенным **image_gen**, с реальной иконкой Kat как референсом. Исходные результаты сохранены в `sources/`: Header 1915×821, Search Results 1536×1024. Затем выполнен обычный экспорт с масштабированием до размеров Apple и профилем sRGB; это не нативная генерация 4K. Промпты и решения — [prompts.md](prompts.md), контрольные суммы — [manifest.json](manifest.json).

Требования сверены 14.10.2026 по официальной [спецификации Apple](https://developer.apple.com/help/app-store-connect/reference/app-information/creative-assets-specifications/) и [рекомендациям к композиции](https://developer.apple.com/app-store/asset-best-practices/). Наличие правильных размеров не означает одобрения изображения Apple.
