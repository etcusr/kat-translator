# Исправление проверок выпуска

14 октября 2026. Изменены сборочный скрипт Mac App Store и тестовая инфраструктура; версия приложения и продуктовые движки не менялись. Установка на iPhone, экспорт новой магазинной версии, upload и push в этой задаче не выполнялись.

## Сборочный скрипт

`archive-macos-appstore.sh` больше не подавляет ошибки pipeline архивирования. При сбое Xcode или записи журнала выполнение заканчивается с ненулевым кодом до проверки/экспорта приложения. Фильтр вывода не считает отсутствие предупреждений ошибкой. Каталог версии/сборки создаётся атомарно и не переиспользуется: уже существующий результат сохраняется, для следующей попытки нужен свободный номер сборки. Версия и build проверяются как числовые значения, без компонентов пути.

Пять исполняемых регрессионных тестов запускают реальный скрипт в отдельном временном checkout с подменёнными внешними инструментами. Проверены ошибка сборки после создания частичного app, сохранение старого результата, успешная сборка без строк фильтра, ошибка записи журнала и недопустимые номера. До исправления ошибки воспроизводились; после исправления 5/5 PASS. Дополнительно реальный каталог build65 отклонён без изменения его журнала. Это проверка поведения скрипта, а не новый App Store export.

## Тесты Mac

- Засев и очистка допускаются только для `app.kattranslator`: сверяются Bundle ID, sandbox container ID, точный путь хранилища относительно container home и разрешённый путь после раскрытия симлинков.
- Ошибка удаления распространяется в XCTest. После удаления проверяется отсутствие каталога; только затем удаляется домен настроек, который также проверяется. Opt-in сохранён.
- Два теста на временных папках проверяют отказ для другого контейнера/пути/симлинка, сохранение чужих данных, ошибку удаления, незавершённое удаление, успешную и повторную очистку. Реальный пользовательский контейнер не очищался.
- Исправлен корень репозитория для фикстур. Рендеры и JSON-отчёт пишутся в создаваемые каталоги под `KAT_RUNTIME_REPORT_DIR` либо временный каталог приложения; отсутствующий `.build` больше не ломает тесты.
- Проверка установленных движков использует текущий Mac Index 9B MLX через штатный маршрутизатор и каталог пакетов, routed ASR и установленный английский Piper. OCR-тест использует каталог MLX целиком и восстанавливает прежний выбор модели. Ожидание GGUF-9B и отдельного файла первого MLX-шарда удалено.
- Тест отмены внешнего перевода задаёт исходный язык и язык быстрого перевода явно, затем восстанавливает настройки. Сохранённая одинаковая пара языков раньше обходила перевод и ломала ожидание выполняющейся операции.

## Проверка и ограничения

**Свежая Release-сборка и полный запуск цели MacRuntimeTests завершились успешно: 58 тестов, 51 PASS, 7 штатных opt-in пропусков, 0 ошибок.** Прошли MLX Index9B, OPUS GPU с шестью направлениями/отменой/повторным использованием, Auto, ASR/TTS/Wayu, OCR, реальная загрузка 12 642 764 байт с проверкой целостности и исправленные тесты UI/очистки. Пять регрессионных тестов скрипта и пять проверок документации/галереи также PASS. Синтаксис shell и diff проверены. Итоговый журнал и xcresult: `.build/release-check-fixes-2026-10-14/verified.log` и `verified.xcresult`. Release DerivedData и копия синтетической ASR-фикстуры размещены вне Downloads: первый прогон остановлен после подтверждённого стеком ожидания открытия файла в защищённой папке; настройки TCC не менялись.

Повторный прогон использует `KAT_ASR_FIXTURES` и `KAT_RUNTIME_REPORT_DIR`, а также opt-in `KAT_MLX_INTEGRATION`, `KAT_OPUS_GPU_TEST`, `KAT_AUTO_ROUTING_INTEGRATION`, `KAT_SPEECH_INTEGRATION`, `KAT_REAL_DOWNLOAD_TEST`. Пути `KAT_MLX_MODEL_PATH` и `KAT_OPUS_GPU_PATH` указывают на установленные пакеты. При запуске через Xcode переменные передаются с префиксом `TEST_RUNNER_`. Они не включены; их прежние результаты не считаются свежими. Это прямой Release test-host, не TestFlight и не повтор всей sandbox-приёмки.
