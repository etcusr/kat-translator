# Ручная проверка смысла: длинные тексты и диалоги

20 октября 2026. Синтетический RU↔EN корпус создан перед запуском.
Критерии сохранены в `meaning_checks` у каждого примера в
[фикстуре](../../../tests/fixtures/mac-long-context.json). Проверка выполнена
по полному исходнику и переводу первого прохода; совпадение остальных
проходов проверяется отдельно. Это экспертное чтение одним проверяющим,
не независимая слепая оценка, не COMET/BLEU и не оценка всех языков.

## Вывод о качестве

Полных пропусков реплик, перепутанных сумм или инверсий ключевых запретов
в этих обычных примерах не обнаружено. Однако утверждать «смысл не теряется»
нельзя: есть локальные смысловые потери, особенно отдельные кровати и
ночёвка в длинном английском тексте, а также чуткий сон, полдень и роль гида.
Сохранение одинакового ответа между прогонами подтверждает повторяемость,
а не правильность этого ответа.

Диалоги передавались целиком одним запросом. Приложение сохраняет веса
модели, но создаёт новый контекст генерации для каждого запроса; автоматическая
память последовательных отдельных реплик здесь не реализована и не заявляется.

Два искусственно повторяющихся граничных текста предназначены только для
проверки лимитов. Их ошибки не включены в оценку качества естественных
диалогов; пустой ответ с ненулевым кодом нельзя считать успешным переводом.
