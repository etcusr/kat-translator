## Поведение

- Модель перевода хранится между запросами. По умолчанию выгружается через
  5 минут простоя; в «Настройки → Память» доступны 1–60 минут. Значение сохраняется.
- Таймер относится к переводчику, а не к распознавателю и голосам. Обычный
  конвейер и раньше мог сохранять модель: здесь добавлены ограниченный срок,
  обновление настройки без перезапуска и прозрачная загрузка после простоя.
- Текущий перевод защищён от выгрузки. Следующий запрос после простоя сам
  загружает выбранную модель; это ожидание включено в задержку запроса.
- Смена модели, ручная выгрузка, закрытие конвейера и экономия памяти сохраняют
  явное освобождение ресурсов. Обёртка подключена только на Mac ко всем четырём
  маршрутам: Index 9B MLX, Index 2B Metal, OPUS GPU и OPUS-направления CPU.
- «Настройки → Экспериментально → Переводить по частям — тест» по умолчанию
  выключен. Для Index 9B включает примерно 128 исходных токенов на часть,
  границы предложений/абзацев и потоковый показ. Дополнительный контекст не передаётся.
  Применяется к следующему запросу. Это прежний plain-режим эксперимента, а не
  более медленный вариант с повторным переводом соседнего контекста.
- Неполный текст в голосовом/текстовом экране помечен как незавершённый и
  отделён от итогового ответа. В историю попадает только итог; поздние callbacks
  не заменяют готовый текст. При отмене/ошибке промежуточный экранный текст очищается.
- Выключенный эксперимент сохраняет обычное разбиение только ради ограничений
  бюджета; автоматического дробления на маленькие части нет. iOS-настройки и
  маршрутизация не изменены; общие поля показа по умолчанию выключены.

## Свежие измерения

M3 Pro, одна синтетическая фраза EN→RU из 363 слов, два повтора на прогретой
модели, через основную MLX-реализацию в собранном приложении. Медианы:

| Режим | Полный перевод | Первый callback текста | Первая готовая часть |
|---|---:|---:|---:|
| Обычный | 14,25 с | 1,71 с | 14,25 с (одна часть) |
| Экспериментальный | 14,84 с | 0,67 с | 4,08 с (четыре части) |

Callback обычного режима используется для существующей потоковой озвучки,
но не включает новый промежуточный экранный показ. Это время получения данных
в мосте, не измерение отрисовки пикселей. Первый законченный блок экспериментального
режима занял 4,00–4,16 с. Полное время не сократилось.

Ответы совпали между повторами и посимвольно с прежним Mac Lab для соответствующих
whole/plain-режимов. Известная ошибка plain-режима «будут делить их друг с другом»
сохранена. Контекст и качество могут ухудшаться; режим не включён автоматически.
[Предыдущая подробная проверка смысла](../mac-chunk-context-2026-10-20/quality-review.md).
[Свежие результаты](runtime.json), [сводка](summary.json).

## Проверки и ограничения

- OfflineCore: 336 тестов, 3 необязательных пропуска, без ошибок. Включены
  защита активного запроса, повторное использование, смена модели, смена таймера,
  освобождение после простоя, восстановление после ошибки загрузки, отменённый
  ожидающий запрос, покрытие исходного текста и отделение неполного ответа от итогового.
- Основная Mac Release test-build и строгая проверка подписи прошли.
- Две реальные MLX-проверки прошли: native limits/cancel/reuse/routing и новая
  проверка хранения/простоя/повторной загрузки/режимов. Длинные запросы не
  перезагружают модель; после ускоренного таймера 0,1 с происходит новая загрузка.
  Отмена по callback и следующий успешный перевод проверены в обоих режимах.
- Реальные Index 2B, OPUS-направления и OPUS GPU прошли ещё две hosted-проверки,
  включая шесть направлений GPU, отмену и переключение маршрутов. Проверка
  маршрутизации со spy также прошла. Две проверки EN/RU-документации прошли.
- Девять Python-проверок MLX прошли; локализация RU/EN/ES/TR (679 записей) прошла.
- Первоначальный запуск XCTest не получил opt-in переменные и пропустил две
  MLX-проверки. Повторный запуск с TEST_RUNNER_KAT_* действительно выполнил обе.
- Нет утверждения об ускорении на всех текстах, о полном сохранении смысла или
  о независимой памяти диалога. Голос/микрофон/OCR и реальные экранные клики
  отдельно не прогонялись. Полный интервал 5–60 минут не ожидался: проверена
  та же логика с коротким тестовым интервалом. Веса и параметры генерации не менялись.
