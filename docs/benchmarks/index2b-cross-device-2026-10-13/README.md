# Index 2B vs 9B: Pixel 9 Pro, iPhone 17 Pro, Mac M3 Pro — 12–13 октября 2026

Запрос пользователя: проверить Index 2B на iPhone и Mac, сравнить скорость трёх устройств и учесть качество перевода. По его просьбе использованы две статьи, без большого корпуса.

## Метод

- Статьи: короткая новость RU→EN (797 символов; локальный текст пользователя, в Git не входит) и NASA «shake» EN→RU (3450 символов, `tests/fixtures/article-device-benchmark.json`).
- Модели — официальные GGUF Q4_K_M: Index 2B (SHA `044b313d…`) и Index 9B (SHA `9cc6758b…`). Промпт тот же, что в приложениях, greedy, загрузка модели не входит в время.
- **Mac M3 Pro / 18 ГиБ:** `llama-completion` и `llama-server` из pinned llama.cpp, Metal, без MTP. Замеры сделаны до сборки iOS, чтобы сборка не влияла.
- **iPhone 17 Pro, iOS 27.0.1:** временная тестовая сборка Kat 0.5.6 (36) из текущего дерева (`testCompactModelsOnDevice` в `tests/benchmarks/ArticleDeviceBenchmarkTests.swift`). Использован штатный `LlamaTranslationBackend` с Metal и MTP2, как в приложении. 2B скопирован в `Documents/kat-bench` приложения по USB; 9B — уже установленный. Порядок: 2B, затем 9B, по два прохода, пауза 10 с. 9B шёл в thermal state 1 (fair), 2B — в 0.
  - После теста собрана и установлена обычная 0.5.6 (36) из закоммиченного проекта. Тестовые файлы в `kat-bench` обнулены: у `devicectl` нет удаления, пустые файлы-заглушки остались.
  - `scripts/generate-project.py` упирается в устаревшую галерею анимаций (`update-animation-gallery.py --check`). Её изображения исключены из Git по правилам приватности. Для тестовой сборки проверка пропускалась без изменения скрипта. Сгенерированный проект после теста возвращён из Git.
- **Pixel 9 Pro:** `llama-completion` на Vulkan под неизменённым `thermal_control.py`, без MTP. Отдельно приведены цифры из приложения 0.3.8.

## Скорость, с

| Статья | Модель | Mac (Metal) | iPhone (Kat, MTP2) | Pixel (Vulkan) | Pixel, приложение |
|---|---|---|---|---|---|
| Новость RU→EN | 2B | 2,1–2,3 | 3,4 | 14,8 | 17,1–18,5 |
| Новость RU→EN | 9B | 7,2–7,4 | 13,5–13,7 | 51,4 | ~46 (с MTP, ранее) |
| NASA EN→RU | 2B | 13,2 | 25,9–26,7 | 82,2 | — |
| NASA EN→RU | 9B | 47,7 | 119,8–123,9 | не завершён* | — |

\* На Pixel 9B дважды остановлен термозащитой G3D 65 °C: через 143 с и 92 с. К остановке готово около 40% текста. Оценка по скорости — около 300 с; это **не замер**.

Детали:
- Mac, llama-bench: 2B — ~1100 ток/с ввод, 80 ток/с генерация; 9B — ~250 / 23.
- Загрузка модели на iPhone: 2B — 1,7 с, 9B — 6,9 с.
- Первый токен на iPhone: 2B — 0,3–0,7 с, 9B — 1,1–4,6 с.

Выводы по скорости:
- 2B быстрее 9B в 3,5–4,7 раза на всех устройствах.
- На одной модели iPhone быстрее Pixel примерно в 3–4 раза, Mac — в 6–7 раз. Причина в памяти и GPU Pixel, а не в настройках (см. [аудит](../../android/benchmarks/2026-10-12-pixel-speed-audit/README.md)).
- Методы различаются: iPhone с MTP2, Mac и Pixel через llama.cpp без MTP. Поэтому межплатформенные соотношения ориентировочные.

## Качество (Mac, тот же промпт, 2B и 9B бок о бок)

- **4 статьи NASA EN→RU** (те же, что в старом прогоне 9B 9 октября; разбиение по абзацам, ≤1100 токенов на часть):
  - 2B — 13–41 с, 9B — 48–155 с. Числа сохранены обеими моделями; у 9B в одной статье «10» передано словом.
  - Русский у 2B заметно хуже: грамматические ошибки («важный испытание», «Пройдание», «двигателные»), смешанная латиница («Неосcurенный», «Рoman»), больше английских слов без перевода.
  - Известные огрехи 9B остались прежними: «термовакuumное», «Луноходная».
- **Кейсы с эталоном** (`tests/fixtures/index-mtp-cases.json`), chrF:
  - EN→RU: 2B 80,8 / 77,0, 9B 91,9 / 80,2;
  - RU→EN: 2B 69,6 / 65,9, 9B 68,3 / 60,7.
  - В синтетическом кейсе `travel_ru` 2B пропустил первое предложение.
- **8 фраз RU → 13 языков:**
  - 2B передаёт смысл и числа, но чаще ошибается в лексике. «Путь» поезда: «dritten Zugweg», «tercer destino», «第三ルート», «3번 노선»; также «der Konzert», «sa vieille appartement».
  - 9B почти везде точнее и естественнее.
  - Украинский результат 2B из выводов исключён по замечанию пользователя: остаточные русские слова там некритичны.
- Проверка ручная и на малом наборе; это не формальная оценка качества.

## Выводы

- **Android:** оставить Index 2B быстрой многоязычной опцией, а 9B — «максимальным качеством». На Pixel 9B медленный и на длинных текстах упирается в термолимит.
- **iPhone и Mac:** 9B уже достаточно быстрый (короткая новость за 7–14 с). Переход на 2B ухудшил бы качество ради выигрыша в несколько секунд. Внедрение 2B на Apple не предлагается.
- Сырые логи и полные переводы лежат локально в `.build/pixel-speed-audit-2026-10-12/{mac,quality,runs}` и `.build/ios-compact/`, в Git не входят.
