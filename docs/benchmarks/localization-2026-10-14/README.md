# Испанский и турецкий интерфейс — 14 октября 2026

Добавлены ES/TR к RU/EN на iOS, macOS и Android: настройки, подготовка языков и моделей, история, ошибки, уведомления загрузок и разрешения Apple. Черногорская локализация не добавлена; при отсутствии поддержанного языка системы используется английский. Выбор языка интерфейса не меняет языки перевода.

## Проверки

- Статическая проверка 670 записей Apple: покрытие RU/EN/ES/TR, параметры и охват строк UI — PASS.
- Сгенерированные словари Android совпадают с общим каталогом и дополнительными Android-строками — PASS.
- OfflineCore: 4 теста выбора языка, сохранённого значения и формата размеров — PASS.
- Android: компиляция Debug и unit-тесты, включая 4 новых теста локализации — PASS.
- Release-сборки iOS для устройства и macOS — PASS.
- В скомпилированных каталогах обеих сборок проверены RU/EN/ES/TR, подстановки и формы срока хранения для 1, 2, 5, 21, 22, 30, 365 дней — PASS.

Команды: `python3 scripts/validation/check-localization.py`, `python3 scripts/generate-android-ui-strings.py --check`; для проверки скомпилированных строк `scripts/validation/localization-probe.swift` собирается вместе с `OfflineCore/L10n.swift` и получает путь к приложению.

## Границы результата

Это проверка исходников, сборки и строк, не визуальная приёмка всех экранов и не редактура носителями языка. Приложения на телефонах и установленный Mac-выпуск не заменялись. Отдельная подготовка iOS build46 и перенос контейнера не входят в результат локализации. Страны распространения в магазинах не менялись.
