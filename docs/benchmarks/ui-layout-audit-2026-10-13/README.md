# Автотесты раскладки интерфейса — 13 октября 2026

Запрос пользователя: на Pixel «не совсем ровно некоторые пункты» в «Моделях»; нужен автотест на проверку интерфейса и его элементов.

## Что найдено и исправлено (Android 0.4.4, code 19)

- Текстовые кнопки внутри карточек (`TextButton`) имели внутренний отступ 12 dp и стояли правее остального текста. Это «Настроить языки и загрузку», «Выбрать направления», «Удалить», «Импорт», «Использовать для распознавания», ссылки на источники и др.
  - Теперь `contentPadding=GroupActionPadding` (0 dp по горизонтали).
  - Автотест нашёл «Удалить», «Импорт», «Использовать для распознавания» до исправления.
- «Рекомендуется» / «Выбрана» / «Пакеты для перевода готовы» были крупнее подписей. Теперь общий `Status` (14 sp).
- «4 языков» → `languageCount` («4 языка»).
- «Ваши языки»: если всё для выбранного уже скачано, внизу «Всё нужное уже скачано», «Скачать» неактивна, а «Готово» сохраняет выбор (как на iOS 0.5.11 и Mac 0.6.4).

## Автотесты

- **Android `UiLayoutAuditTest`** (instrumented, только чтение).
  - Открывает «Модели», «Ваши языки», «Настройки» и прокручивает их.
  - В каждой карточке `Group` (тег `ui.group`) первый элемент строки должен начинаться на текстовом крае карточки (+16 dp).
  - Сдвиг 2–24 dp считается ошибкой; ≥24 dp — ведущая иконка.
  - Предзагруженные, ещё не размещённые элементы LazyColumn пропускаются.
  - Pixel 9 Pro: OK, 22 с.
- **iOS `testPanelScreensAlignLineStarts`** (XCUITest, только чтение).
  - Проходит «Модели» и «Ваши языки». Края текста — начала строк, общие хотя бы для двух строк; одиночное начало в 4–24 pt от ближайшего края — ошибка.
  - iPhone 17 Pro: OK.
  - Отрицательная проверка: сдвиг «Проверить снова» на 12 pt тест ловит.
  - Ограничение: в стандартных списках SwiftUI (`List`) строка из одного элемента отдаёт рамку всей ячейки. Поэтому сдвиг внутри такой строки XCUITest не видит; тест полезен для собственных раскладок (ScrollView/VStack).
- Mac UI-тесты не запускались: нет разрешения Accessibility.
- Статические проверки шрифтов и чисел — `scripts/validation/test_ui_typography.py`, `test_docs_app_parity.py`.

## iOS 0.5.13 (43), Mac 0.6.6 (59), Android 0.4.5 (20): единицы, переключатели, нижняя панель

Запрос: на iPhone в «Ваших языках»
1. ГБ/МБ при английском интерфейсе;
2. переключатели торчат правее карточек;
3. нижняя панель закрывает переключатель.

- **Единицы.** `ByteCountFormatter` берёт язык системы, а не приложения.
  - Новый `L10n.bytes` (OfflineCore): десятичные КБ/МБ/ГБ на языке приложения, точность как у системного форматтера. Применён во всех экранах Apple, кроме виджета Live Activity.
  - Unit-тест в `L10nTests`.
  - На Android та же ошибка была наоборот («MB» в русском интерфейсе); `bytes` теперь берёт язык приложения.
- **Переключатели.** Рамка переключателя у XCUITest совпадает с карточкой (20–382 pt), но системная капсула рисуется на 2 pt дальше. Тест теперь проверяет пиксели снимка экрана (правый край лаймовой капсулы против края карточки). Он воспроизвёл проблему: «toggle drawn 2 pt right of the cards». Исправлено: на iOS отступ справа 4 pt.
- **Нижняя панель.** Непрозрачный фон с разделителем, под содержимым отступ 24 pt. Тест проверяет, что в конце прокрутки карточка моделей и последний текст выше панели.
- **Тесты.**
  - iOS: `testPanelScreensAlignLineStarts` (+ единицы, + пиксели переключателей, + нижняя панель) и `testOpusDirectionsSelectionShowsTotal` — passed.
  - Pixel: `UiLayoutAuditTest` (+ проверка единиц в русском интерфейсе) — OK.
  - Mac: `testLanguageSetupAlignsLineStartsAndActions` — passed.
  - Все три шли параллельно. OfflineCore: 266 тестов, 0 ошибок.
- **Сборки.**
  - Android: APK `dist/android/kat-translator-0.4.5-debug.apk`, SHA-256 `05696602e97eadf09d5fc5efb3194c9b6d71f0139d6d9578e4f54f64f1d1aeff`.
  - iOS и Mac установлены. Mac подписан, 0.6.5 сохранена в `.build/mac-app-backup`.
  - В `dist/macos`: 0.6.6, 0.6.5, 0.6.4 и совместимая 0.6.0. В `dist/android`: 0.4.5, 0.4.4, 0.4.3.
