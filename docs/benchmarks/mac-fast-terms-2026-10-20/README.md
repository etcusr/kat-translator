# Ускорение автословаря — Mac, 20 октября 2026

Отдельная Kat Context Lab, RU→EN, Index 9B MLX/MTP2 на M3 Pro. Тот же частный исходник: 5 OCR-блоков / 2574 символа / 8 частей. Цель — уменьшить подготовку прежнего автословаря без потери его полезных исправлений. Основное приложение, его настройки и сборки магазинов не изменялись.

## Библиотеки и метод

Проверены первичные описания [pymorphy3](https://github.com/no-plagiarism/pymorphy3), [YAKE](https://github.com/INESCTEC/yake), [KeyBERT](https://github.com/MaartenGr/KeyBERT). pymorphy3 связывает формы русских слов; YAKE ранжирует ключевые слова статистически без обучения; KeyBERT использует эмбеддинги. Ни одна из этих функций сама по себе не заменяет контекстный перевод термина.

Локальные пробы на исходнике: инициализация pymorphy3 около 26 мс, разбор около 20 мс; YAKE около 9–11 мс после импорта (~561 мс). Это отдельные CPU-пробы, не статистика полных переводов. Стандартный YAKE top20, n=3 преимущественно выделяет фразы начала статьи и не включает нужный повторяющийся термин. KeyBERT не устанавливался и его скорость не измерялась. В рабочем эксперименте используется **pymorphy3 2.0.6** с локальными словарями; YAKE остался исследовательской пробой. Зависимости изолированы в `.build`, их установку описывает [README](../../../scripts/research/mac-context-terms/README.ru.md); в runtime основной Kat они не добавлены.

Два новых режима:

1. **Узкий (`fast_terms`)**: группировать повторяющиеся выражения в кавычках по нормальным формам, максимум четыре; при отсутствии таких выражений брать повторяющиеся существительные. Здесь выбраны два выражения. Передавать модели первые два предложения основного текста и соседние предложения вокруг первого употребления. Ответ — только массив английских переводов, без генерации исходных слов, ключей JSON и пояснений.
2. **Расширенный (`focused_terms`)**: дополнить этот список повторяющимися обычными существительными, всего до десяти. Дополнительный проход исключает имена, географические названия и сокращения; использует уже отобранный контекст. Здесь получилось семь записей, включая обозначение налёта.

Английские соответствия определяет та же Index 9B. Ни ручной словарь, ни известный английский перевод в подготовку не передаются. Все исходные варианты проверяются на наличие в документе; список строится заново для каждого запроса. Нет постобработки с подменой aircraft на drones, кеша готовых словарей или изменения весов. Каждая часть получает только релевантные записи. Морфологические словари переиспользуются, кеш разбора слов ограничен документом.

## Почему одного сокращения недостаточно

Диагностические пробы, не включённые в итоговые медианы:

- Прежний запрос читает 742 токена и выдаёт около 504 символов JSON; в предыдущем опыте подготовка занимала 6,81 с. Примерно 2,85 с приходилось на первый токен, остальное — преимущественно генерация/завершение.
- Сокращённый ответ по полному тексту: 709 входных токенов, один пробный вызов 4,09 с. Сохраняется цена чтения всего документа.
- Два отобранных термина с локальными соседними предложениями: 229 токенов, прогретая подготовка 1,31 с, но ошибочное **long-range aircraft**. Этот вариант отвергнут по качеству.
- Добавление начала статьи: 302 токена, проба 1,80 с, возвращает **long-range drones**. Узкий полный перевод всё же оставляет offensive для налёта.
- Расширенный список: 330 токенов; диагностические вызовы 2,53 с / 1,91 с возвращают семь коротких переводов, включая drones и raid. Полная оценка — в таблице ниже.

Это поиск решения на известном примере, не слепая проверка на независимом корпусе. Сокращение контекста может закреплять неверную интерпретацию; скорость без проверки смысла недостаточна.

## Измерения

Заключительная серия: одна модель в памяти, три режима × отдельный полный прогрев + три измеряемых повтора с циклической сменой порядка. 12/12 успешных запросов; прогревы не входят в медианы. Загрузка модели измеряется отдельно. Полное время и время первой содержательной части **включают** CPU-отбор и предварительный перевод словаря. OCR, отрисовка и TTS исключены; первая содержательная часть исключает короткий заголовок. Это замеры обычной рабочей машины, не изолированного стенда.

| Режим | Подготовка словаря | Первая содержательная часть | Весь перевод | Диапазон полного времени |
|---|---:|---:|---:|---:|
| Текущий, без словаря | — | 3,51 с | 16,90 с | 16,84–17,44 с |
| Прежний полный автословарь | 6,78 с | 10,39 с | 24,37 с | 24,17–24,45 с |
| Быстрый расширенный | 1,97 с | 5,51 с | 20,14 с | 19,99–20,51 с |

Подготовка быстрее на **70,9%**, первая содержательная часть — на **47,0%**, полный перевод — на **17,4%** относительно прежнего автословаря. Подготовка не бесплатна: до быстрого перевода без словаря остаётся около двух секунд дополнительного ожидания первой части. Словарь строился заново каждый раз; ручной подготовки нет. Публичные тайминги/хэши: [основная серия](summary.json).

Ранняя отдельная серия (16/16 запросов, четыре прогрева + три измеряемых повтора каждого режима) сравнивала узкий отбор с ручным словарём и обоими контролями. Медианы первая часть/полностью: текущий 3,71/17,62 с; ручной 3,59/19,24 с; полный авто 10,44/25,09 с; узкий быстрый 5,11/19,29 с. У узкого варианта остаётся offensive, поэтому он не выбран лучшим компромиссом. Эти цифры не смешаны с заключительной серией; ручная подготовка не измерялась. [Ранняя серия](sparse-summary.json).

### Качество

Во всех трёх повторах расширенного режима совпали полные переводы и все семь соответствий. Оба «дальнолёта» — **long-range drones**, «налёт» — **raid**, написание Baltic Corridor согласовано. Скачков к aircraft/offensive нет. Все контрольные числа 1015, 16, 250, 300 сохранены. Эти же числа сохранены в остальных режимах.

Перевод не идентичен прежнему автословарю. Расширенный вариант добавил **direct** в «direct hits», хотя такого буквального уточнения в исходнике нет. Есть различия стиля и капитализации district. Bely Island и front line по-прежнему не извлечены автоматически: там остаются White и line. Ручной словарь в ранней серии сохраняет эти преимущества. Ключевые исправления выдержаны, но утверждать полную равнозначность качества или отсутствие других ошибок нельзя. Независимый корпус не тестировался.


## Ограничения

Один известный русский документ и английское направление; никаких обещаний качества на всех языках/текстах. Отбор повторов намеренно охватывает меньше произвольных сущностей, чем полноценный анализ документа; даже расширенный вариант не извлёк Bely Island и front line, которые были заданы вручную в прошлом опыте. Морфология без контекстного снятия омонимии и простое выделение предложений могут ошибаться. Дополнительные существительные могут иметь разные значения в разных местах. Английский target проверяется структурно, но не семантически; модель может проигнорировать соответствие.

При отсутствии кандидатов режим явно возвращает пустой словарь и переводит без предварительного вызова модели. Некорректный JSON/число соответствий, ошибка движка или отобранный контекст сверх 1024 токенов вызывают явную ошибку, без скрытого переключения на старый режим. Длинные документы, другие языки и поведение без кавычек требуют отдельной оценки. Короткие примеры без повторов не получают преимуществ словаря.

Скриншот обрывается на «виртуальными sim-»; достроение его конца не доказывает перевод невидимого продолжения. Оценивалась верность перевода, а не достоверность утверждений статьи.

## Проверки

22 локальных теста прошли: реальная морфология, контекст темы, дополнение существительных, отсутствие ручной подсказки, изоляция документов, пустой отбор, лимит и проверка ответов. Обе серии подтвердили точное совпадение границ с производственным Swift-планировщиком. 28/28 полных запросов (21 измеряемый и 7 прогревочных) успешны. Отдельная реальная проверка собранной Swift-программы через её Python-мост получила тот же перевод и все семь соответствий; время этого функционального прогона 21,07 с не входит в сравнительные медианы.

Подпись лаборатории и две проверки документации прошли. Настройки основной Kat до/после совпали; веса модели, runtime и планировщик сверены по SHA-256 с предыдущим опытом. [Проверки](verification.json), [происхождение и версии зависимостей](provenance.json). Нативная автоматизация кликов/доступности не проводилась.

Kat Context Lab открыта с сохранёнными результатами; кнопка перевода выполняет новый запрос. В меню есть «Быстрый · узкий» и «Быстрый · расширенный», словари показаны отдельно для каждого режима. Частные исходник, переводы, диагностические выводы и bundle находятся только в игнорируемой `.build`; в Git не включены. Установленная основная Kat не заменялась; загрузки в Store и push не выполнялись.
