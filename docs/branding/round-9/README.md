# kat translator — случайные направления

Варианты визуальной концепции. Шесть растровых эскизов созданы встроенным image_gen. Промпты — в prompts.json. Приложение не изменено.

1. [Штамп](stamp.png) — узкий грубый шрифт с жёлтым акцентом.
2. [Пиксели](pixel.png) — скобки и курсор на синем фоне.
3. [Каллиграфия](calligraphy.png) — свободное написание тушью.
4. [Абстракция](abstract.png) — три цветные формы.
5. [Оптика](optical.png) — полосы и излом.
6. [Стекло](glass.png) — объёмная мятная k.

Это направления, не готовые производственные логотипы. Каллиграфия требует отдельной упрощённой иконки, штамп — версии без мелкой текстуры, стекло — плоской монохромной версии. В оптическом знаке генератор нарисовал больше полос, чем задано. Малые размеры пока не проверены.
