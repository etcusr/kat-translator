# Кот-волшебник — ожидание обработки

7 октября 2026. Пользователь отклонил плоскую рисованную версию (предпросмотр сохранён как vector-rejected.gif). Вместо неё используется предоставленный cat-wizard.mp4: локальный бесшумный AVQueuePlayer + AVPlayerLooper. Исходный файл 87 701 байт, 166×152, 10 кадров/с, 3,8 секунды, без аудиодорожки. Видео и статичный первый кадр находятся в App/Resources/CatWizard. Предпросмотр: [preview.gif](preview.gif).

Индикатор заменяет круг ожидания в голосовой вкладке и появляется слева в нижней панели текста. Показывается при обработке после записи, переводе и ожидании подготовленной озвучки. При реальном воспроизведении исчезает, возвращаются существующие стоп/пауза; отмена обработки доступна. Не добавляет фиктивных процентов. Существующий измеряемый прогресс длинного перевода сохранён. Во время записи предварительный перевод не закрывает управление микрофоном.

Плеер не меняет AVAudioSession, всегда muted/volume0. В фоне и при Reduce Motion плеер приостанавливается, виден статичный первый кадр; при удалении индикатора очередь/наблюдение очищаются. Индикация декоративная и скрыта от VoiceOver; реальный этап остаётся текстом. Это пользовательский референс для текущей разработки; источник и права на ролик для публичного релиза не проверялись.

Состояние isWaitingForSpeech отделяет синтез/загрузку голоса от реального воспроизведения. Сбрасывается при выходе, ошибке и отмене. ConversationPipelineTests: 46 тестов, 0 ошибок; новый тест проверяет ожидание синтеза, исчезновение индикатора при начале воспроизведения, отмену до и после подготовки. Лог:.build/wizard-pipeline-tests.log. Фактическую плавность ролика рядом с нагруженными моделями на телефоне ещё не измеряли.

Экран блокировки: прежняя статичная поза с обновлением положения сохранена.
