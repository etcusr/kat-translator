# kat translator — раунд 8

Четыре концепта после подключения навыков logo-design и brand-identity из rampstackco/claude-skills. Созданы встроенным image_gen; промпты и ссылки на источники навыков — в prompts.json.

## Бриф

Офлайн-переводчик для повседневного общения и поездок. Название kat translator. Простая выразительная графика, без котов-стикеров и сложных монограмм. Основные применения: иконка iPhone, заголовок приложения, страница магазина. Это исследование формы; финальная айдентика не утверждена.

## 1. Реплика

![Реплика](reply.png)

Знак + гуманистический гротеск. Две встречные реплики; крупные массы и широкий просвет. Палитра брифа: #171B19, #174B3D, #F4F1E8. Иконка использует знак без текста. Ограничение: близок к распространённым символам общения, самостоятельность формы нужно проверить перед выбором.

## 2. Языковой билет

![Билет](language-ticket.png)

Знак + массивные мягкие засечки. Билет как доступ к общению в поездке, диагональ разделяет языки. Палитра брифа: #20201D, #F1C547, #F5F1E6. Силуэт прост, но может восприниматься как приложение билетов. В генерации немного различаются пропорции выемок — унифицировать при векторной отрисовке.

## 3. k — переход

![Переход](k-crossing.png)

Шрифтовой логотип с самостоятельной буквой-знаком. Палитра брифа: #182124, #ED4B35, #F3F3EE. Иконка наследует букву названия. Просвет в месте соединения требует проверки в 28–60 px; возможно, понадобится расширение. Пропорции подписи translator стоит уменьшить в следующей итерации.

## 4. Короткая реплика

![Шрифтовой](quick-aside.png)

Шрифтовой логотип с наклоном и точкой; для иконки k. Палитра брифа: #4E2037, #F7E6E7. Более живой характер без персонажа. В генерации буквы соединены сильнее, чем предусматривал бриф; это самостоятельный вариант для оценки, не точное исполнение задания.

## Ограничения и следующий этап

Все изображения — растровые эскизы, не готовые SVG. Шрифты нарисованы генератором, конкретная гарнитура не подтверждена. Указанные HEX — заданные цвета, не измеренные пиксели. Приложения внутри листов — иллюстрации использования, а не подтверждение прохождения теста на реальном размере. После выбора: единая векторная геометрия, проверка иконки 28/40/60 px, монохрома и инверсии, проверка сходства с существующими знаками. Файлы приложения не менялись.
