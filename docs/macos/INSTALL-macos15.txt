Kat translator — совместимый выпуск для macOS 15–26

Требуется Mac с Apple Silicon (M1 и новее). Это отдельный вариант для macOS 15–26; на новых macOS также запускается.
Перетащите Kat translator в «Программы», подтвердив замену, если приложение уже установлено.
Используется тот же пакет Index MLX + MTP2, что и в основном выпуске. Дополнительная модель для совместимости не нужна.
История, настройки и загруженные модели хранятся отдельно от приложения и сохраняются при замене.
Сборка подписана Apple Development, без Developer ID и нотариальной проверки Apple.
Если macOS блокирует первый запуск, откройте «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть».

Сохранённый совместимый выпуск: 0.6.0/build53, Index 9B MLX+MTP2 и OPUS CPU.
Новые функции современного выпуска (Index 2B, OPUS-направления и «Авто» перевода) сюда не включены.
Минимум macOS 15 проверен по бинарным зависимостям; испытание на физической macOS 15–26 ещё не выполнено.
