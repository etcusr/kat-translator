# Необязательный переводчик OPUS Big

[English](IMPLEMENTATION-opus-big.md) | **Русский**

**Текущий охват (13 октября 2026):** старый пакет EN↔RU/UK/BE использует PyTorch Metal FP16 на современном Mac и CTranslate2 CPU INT8 на iOS/Android. Отдельный каталог теперь содержит 54 пакета направлений OPUS, включая прямые пары без EN; все три платформы выполняют их через CT2 CPU. Начальный выбор перевода — «Авто»; сохранённый ручной выбор не сбрасывается. См. [текущее состояние](CURRENT_STATE.ru.md), [интеграцию направлений](android/benchmarks/2026-10-13-opus-directions/README.md) и [доказательства GPU для старого пакета на Mac](benchmarks/mac-opus-gpu-release-2026-10-12/README.md).

## Историческая первоначальная интеграция EN-пакета

Остальная часть документа описывает исходную интеграцию EN-пакета на Apple, её прежние значения по умолчанию, интерфейс и пути. Она не описывает текущий планировщик «Авто» и полный каталог направлений.

OPUS Big — дополнительный выбор модели на macOS и iOS. План загрузок на экране выбора языков рекомендует OPUS для русского ↔ английского; при добавлении других языков сохраняется рекомендация Index/Qwen с широким охватом. Рекомендация применяется, только когда пользователь запускает этот план. Выбор существующих пользователей и запасной вариант по умолчанию (Index) сохраняются, нативный runtime Index не меняется. Пакет поддерживает английский ↔ русский, украинский и белорусский (шесть прямых направлений). Скрытого pivot между тремя славянскими языками нет. Ввод на том же языке обрабатывается существующим сквозным поведением.

Сведения о модели описывают меньший объём загрузки, меньший расход памяти и офлайн-работу, а также ограничения качества на сложных текстах. Выбор языка и сведения о модели перечисляют только четыре поддерживаемых языка.

## Файлы и runtime

- `App/Resources/opus-package.json` закрепляет все 12 загрузок по ревизии, точному размеру и SHA-256. Полный пакет — 492 650 422 байта. Нужны оба направления, обе пары токенизаторов SentencePiece, словари и лицензии.
- Исходные веса: Helsinki-NLP `opus-mt-tc-big-en-zle` и `opus-mt-tc-big-zle-en`. Публичная конвертация INT8: `crash-sv/scribe-translate-ct2`, ревизия `366ea5f4bd2bc417a7430006408a0c6cd72a9f91`, CC BY 4.0.
- CTranslate2 4.6.0 (`617405f4b050e994e829d527da6caa0e0030afe7`) и SentencePiece 0.2.1 (`31646a467d2051eb904e0b45de3a73e91fe1c1e3`). Нативный CPU INT8_FLOAT32 с Ruy и Accelerate, четыре потока и beam size пять. Это отличается от прежнего замера OPUS на Python/Metal.
- `scripts/build-opus-runtime.sh` собирает фреймворки для arm64 Mac, iOS и симулятора. Он никогда не пересобирает и не заменяет runtime Index. `mobile-cancel.patch` добавляет проверки отмены в greedy/beam-декодирование и учитывает Apple deployment target вызывающего проекта. Уведомления о лицензиях runtime и модели поставляются в `opus-notices.json`.
- `RoutedTranslationBackend` выбирает движок и выгружает прежнюю модель при переключении. OPUS загружает веса только одного направления за раз. Голос, текст, камера/изображение и интеграция macOS используют один маршрут.
- Ввод делится по предложениям и абзацам исходника, затем дробится дальше, чтобы уложиться в 480 токенов. Требуется конец последовательности; достижение лимита вывода вызывает повтор с меньшими фрагментами. Обрезанный результат никогда не принимается как полный перевод. Во время inference сеть не используется.

## Загрузка и предварительная установка

`OpusPackage` использует существующие докачиваемые экземпляры `ModelDownloader` и проверенный атомарный установщик `PackageStore`. Готовность требует полного пакета, а не только первой модели. На странице моделей одна общая строка загрузки/паузы/отмены/удаления. Завершение загрузки в фоне может собрать полный пакет.

Путь локальной предварительной установки на устройстве — `Documents/DevelopmentModels/opus-big/{en-zle,zle-en}`. Файлы сверяются с тем же манифестом загрузки до установки в `Application Support/OfflineTranslator/TranslationPackages/opus-mt-big-en-zle-int8`. После успешной проверки удаляется только эта промежуточная папка. Существующие файлы Index/ASR/голосов переиспользуются и сохраняются.

## Проверка

Изолированная лаборатория `/Users/USER/Downloads/kat-translation-lab-2026-10-10` содержит замороженный корпус из 18 текстов RU↔EN, три нативных повтора OPUS, проверки шести направлений, доказательства отмены и разбор качества (`OPUS-NATIVE.md`). На M3 Pro две полные статьи заняли 10,20 с EN→RU и 4,64 с RU→EN; измеренный пиковый RSS процесса — 486,6 МБ. Это отдельные замеры на Mac, а не утверждения о скорости на iPhone.

Тесты ядра охватывают все четыре языка, ограничения прямых пар, восстановление значения по умолчанию и разбиение без потерь. Runtime-тесты на Mac проверяют маршрутизацию/выгрузку; общие `OpusUITests` используют реально установленные веса, шесть направлений, фильтрацию языков и сведения о модели на обеих платформах. Результаты тестов на устройствах сохранены в `.build/opus-integration/`.

Отдельное сравнение движка Index завершилось, а его аудит неизменённого проекта прошёл до начала этой интеграции. Все 162 результата Index совпали, медианное отношение скорости — 1,001×. Экспериментальный обновлённый runtime Index остаётся только в лаборатории.
